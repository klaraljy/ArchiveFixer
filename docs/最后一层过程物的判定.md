# 最后一层过程物的判定

本文是 2026-11-08「第二大步最终内容分卷组失败判定」的实施口径。  
只讨论最终内容组不完整、损坏、密码错误以及最后一层过程物的身份与处置，不改第一大步的交接语义。

## 1. 问题

链：

```text
111-1.rar -> 222-1.zip -> 333-1.7z.003
111-2.zip -> 333-1.7z.002
111-3.7z  -> 333-1.7z.004（缺失或损坏）
000-4.rar -> 333-1.7z.001
```

当 `333-1.7z.004` 缺失或损坏时：

- 333 组没有最终内容；
- 不能把 333 的片当内容物；
- 不能因为各包装层解压动作成功就判整条链成功；
- 不能删源包；
- 需要识别哪些是最后一层过程物，并按普通档/空间不足档处理。

## 2. 身份与终态

### 2.1 分卷组事实

```text
Completeness = Complete      片齐
Completeness = Incomplete    缺片
Integrity = Corrupted        片存在但数据损坏
FinalContentVerified = false 没有可发布的最终内容
SourceRemovalAllowed = false 源包不得删除
```

### 2.2 终态表

| 场景 | 组事实 | TaskReason | TaskOutcome | 最终内容 |
|---|---|---|---|---|
| 完整、内容校验通过 | Complete | — | Succeeded | Verified |
| 完整、密码错误 | Complete | PasswordExhausted | Failed | 无 |
| 完整、片损坏 | Complete + Corrupted | FinalGroupCorrupted | Failed | 无 |
| 缺片 | Incomplete | FinalGroupIncomplete | Failed | 无 |
| 第一大步分卷成员 | 交接 | — | Skipped | 不适用 |

第二大步的最终内容组不允许把 `Skipped` 或 `PartiallyCompleted` 当作最终结论。

### 2.3 不变量

```text
第一大步：分卷成员只交接，Skipped 不是链结论。
第二大步：最终内容组不完整/损坏 => Failed。
源包：只在组最终内容 Verified 后才允许按源包档处理。
内容：FinalContentState = Missing 时不得发布内容物。
```

## 3. 缺片、坏片、密码错误

### 3.1 缺片

```text
333.004 不存在
=> FinalGroupIncomplete
=> Failed
=> 无最终内容
=> 源包保留
```

### 3.2 坏片

```text
333.004 存在，CRC/数据损坏
=> FinalGroupCorrupted
=> Failed
=> 无最终内容
=> 源包保留
```

坏片不是 `VolumeMissing`，也不是 `Skipped`。  
密码错误不是 `FinalGroupCorrupted`，也不是 `FinalGroupIncomplete`。

### 3.3 密码错误

```text
四片齐、数据正常、密码试完
=> PasswordExhausted
=> Failed
=> 无最终内容
=> 源包保留
```

## 4. 最后一层过程物身份

### 4.1 定义

```text
最后层过程物 = 直接产出最终层输入片的程序生成物
```

不是所有上游包装，也不是整个分卷组。

### 4.2 例子

```text
333.001 <- 000-4.rar      用户源包
333.002 <- 111-2.zip      最后层过程物
333.003 <- 222-1.zip      最后层过程物
333.004 <- 111-3.7z       最后层过程物或源包，按来源优先
```

判定：

```text
用户原包身份 > 过程物身份
```

因此：

- `000-4.rar`：源包，保留；
- `111-2.zip`、`222-1.zip`：最后层过程物；
- `111-3.7z`：用户导入则是源包；程序生成则是过程物；
- `111-1.rar`、`000-1.rar`：不是最后层直接产出者，不能误认。

### 4.3 判不出

```text
缺片找不到产出任务
=> 不强行认定
=> 保留现场，不删源，不猜
```

## 5. 保留策略

### 5.1 普通档

```text
源包：全部保留
最后层过程物：
  RestHandling = Keep   -> 保留
  RestHandling = Delete -> 删除
```

### 5.2 空间不足档

```text
最后层过程物可以释放
源包不得因空间不足被误删
```

### 5.3 不允许

```text
用源包删除出口处理过程物
用最后过程物保留逻辑处理用户源包
把整个分卷组当成一个“过程物文件”
```

## 6. 源包删除闸门

源包删除保持唯一出口：

```text
ReclaimSucceededGroupSources
-> PurgeLayerSourcePackage
-> ResultCompletenessClassifier.AllowsSourceRemoval
```

只有：

```text
组完整 + 最终内容 Verified + 无未消费产出
```

才允许调用。  
最终组失败时：

```text
FinalContentVerified = false
SourceRemovalAllowed = false
不调用 ReclaimSucceededGroupSources
```

## 7. 实现边界

### 7.1 新增事实

```text
TaskReason.FinalGroupIncomplete
TaskReason.FinalGroupCorrupted
GroupFailureKind（Incomplete / Corrupted）
LastLayerArtifacts（Task, Path, IsSource, Exists）
```

新增枚举值放在枚举末尾，避免改变既有整数值。

### 7.2 修改层

```text
DeferredVolumeDeficitStep
VolumeStepStep
ContentGroupFinalizerStep
BatchOutcomeTally
TaskSummaryService / BatchSummaryDiagnostics
StatusToBrushConverter
RestHandlingStep / PartialPublishStep
```

### 7.3 不修改

```text
不放宽第一大步跳过
不全局改 VolumeMissing -> Failed
不把 SizeAnomaly 当失败
不新增下游 RunDeferredSourceMoveWorkAsync 补丁
不新增第二条删除路径
不删用户源包
```

## 8. 测试

### 8.1 单元/集成

每个失败场景断言：

```text
具体最终内容路径不存在
TaskOutcome = Failed
TaskReason = 预期原因
FinalContentState = Missing
源包路径仍存在
最后层过程物集合精确匹配
Keep/Delete 的实际目录存在性相反
```

### 8.2 915 矩阵

普通 50：

```text
40 成功：8 档 × 5，25 Specified / 25 Original
10 失败：5 缺片 + 5 坏片
         5 Specified / 5 Original
         8 档覆盖，每档 6/7
```

```text
50 普通 + 10 特定解压 + 20 异常 + 20 空间不足
```
