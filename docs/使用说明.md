# ArchiveFixer 使用说明

> 适用版本：ArchiveFixer v0.2.4
> 最后核对：2026-11-14
> 面向使用者；开发/判据细节见 `docs/开发/`，历史版本见 `docs/历史/`。

## 1. 这是什么

ArchiveFixer 用来处理来源不明、后缀被改坏、加密、分卷、多层嵌套的压缩包。

它做四件事：

1. 按文件内容识别真实格式，不只看后缀；
2. 一键处理时自动修正可证的伪装后缀，分卷按整组处理；
3. 用密码本/统一密码自动试密码并解压，失败原因写进任务和日志；
4. 把内容物放到落点，把源包和过程物按你选的档位处理。

**它不做什么：**

- 不改压缩包里的内容，不联网，程序本体不写注册表；
- 不自动解压普通图片、视频、音频、文档、文本；
- 默认不动源包；只有你明确选择删除档，且“解压成功 + 输出校验通过”后才处理源包；
- 判不出时什么都不做，不猜、不拿用户源文件做实验。

## 2. 三种拿法

| 形式 | 适合 | 说明 |
|---|---|---|
| 安装包 `ArchiveFixer-0.2.4-setup.exe` | 一般用户 | 向导安装到本机非系统固定盘，可卸载；用户数据固定在 `%LOCALAPPDATA%\ArchiveFixer` |
| 独立版 zip | 不想安装 | 解压即用，自带 .NET 运行时 |
| 框架依赖版 zip | 已装 .NET 8 桌面运行时 | 体积小，需要系统有 Desktop Runtime x64 |

用户数据（设置、密码列表、日志）固定放在 `%LOCALAPPDATA%\ArchiveFixer`，不跟安装目录走。旧版 `data\` 只在第一次启动时只读迁移，不覆盖新数据。

## 3. 30 秒上手

1. 打开程序；
2. 点「添加文件」或「添加文件夹」，也可以把文件/文件夹拖进窗口；
3. 在任务列表里勾选要处理的行；
4. 点「一键处理」；
5. 看确认框里的落点、源包、过程物档位；没问题就确认；
6. 跑完后看任务状态、日志、输出目录。

「添加文件/添加文件夹」是**替换当前列表**；想追加，用菜单「文件 → 追加到列表」。

## 4. 主界面九个页签

| 页签 | 用途 |
|---|---|
| ① 任务 | 导入、勾选、一键处理、暂停/停止、查看任务与日志 |
| ② 解压方式 | 嵌套层数、并发与空间、内容物保留关键词、落点、引擎选择 |
| ③ 清理方式 | 源包操作、失败/部分完成时最后一层过程物操作 |
| ④ 密码 | 统一密码、密码本、密码列表、每层尝试上限 |
| ⑤ 打包 | 选文件夹/文件、密码、落点；分卷与外层由程序按规则决定，页面只显示实际会用的外层 |
| ⑥ 提醒 | 一键处理前确认框、解压前提醒 |
| ⑦ 引擎 | 引擎优先级、UnRAR/Rar/7z 路径、保留受损文件 |
| ⑧ 设置 | 日志、安全上限、恢复默认、关于 |
| ⑨ 说明 | 内置说明、术语、FAQ；快捷键在菜单「帮助 → 快捷键」 |

快捷键：Ctrl+A 勾选全部任务、Ctrl+D 取消全部勾选、Ctrl+I 反选（都作用于勾选）。

### 任务页常用按钮

- **一键处理**：识别 → 修正可证后缀 → 按密码解压/分卷 → 续解 → 收尾。
- **继续解**：上一批达到层数上限、还有内层包时出现。
- **暂停所有操作**：停止当前所有任务，不再处理队列；再点一键处理才继续。
- **停止当前任务**：立即停当前任务，然后继续队列里的下一个。
- **手动操作**：对选中的一行打开单任务操作（只解压、改名、看内容等）。
- **全选 / 全不选 / 反选 / 移除勾选的**：只作用于勾选；移除是纯列表操作，不碰磁盘。
- **特定解压**：只改内容物落点/命名，源包与其余物仍按清理页设置。

## 5. 一键处理会做什么

### 5.1 扫描与识别

- 按内容识别格式；后缀只作弱提示；
- 能识别的分卷后缀单独归类，不会误当普通伪装；
- 媒体前面挂归档、尾部有 ZIP 的文件按“内嵌归档/媒体前缀完整归档”处理；
- 识别结果和证据写进日志；判不出不猜。

### 5.2 普通内容物不碰

图片、视频、音频、PDF/文档、文本、docx/xlsx/pptx/odt/epub/jar 等内容物：

- 自动处理不解压、不递归、不改名、不搬、不删；
- 普通产物只做一次很轻的“是不是归档”判断，结果缓存；
- 只有用户明确导入的源包，或与同基名分卷候选放在一起的文件，才做内容识别；
- 用户明确导入的 docx 等内容容器，手动「只解压」仍可拆；自动路径里的同类文件保留。

真正的 APK 不打开、不递归、不改名。

### 5.3 分卷

- 一组分卷算一个任务，从入口卷开始；
- 7z 数字卷、跨盘 ZIP、RAR partN/老编号都按族判；
- 缺片时只报缺哪几片，不调引擎、不删片；
- 完整组只解一层，用入口层标准名/硬链接，源片不动；
- 失败/部分完成/取消不动源包；
- 判不出就保留原样。

### 5.4 递归与层数

- 一键处理按「最大嵌套层数」跑（②页，1–10，默认 7）；
- 每层识别内层包，继续解；
- 内容物跟上一层并排，中间过路层是否保留由「省略中间续解层」设置决定；
- 到层数上限会停下并报告，不会无限展开。

### 5.5 落点

- 默认“包名 + 同名子文件夹 + 压缩包内那层内容”；
- 指定位置时，内容物落在指定根下的同名子文件夹；
- 不塌缩、不覆盖；同名冲突按冲突策略自动重命名/询问；
- 工作区固定为 `<目标目录>\.ArchiveFixer.work`，不可设置。

## 6. 源包、过程物、其余物

### 6.1 源包

- 默认「留下（KeepInPlace）」：原位置不动；
- 「彻底删除（DeleteInPlace）」：只有解压成功 + 输出校验通过后，才从原位置删除；
- 源包永远不因普通失败/取消被删。

### 6.2 过程物

- 成功链上的中间包/片按固定规则清理；
- 失败/部分完成时，最后一层过程物按③清理方式 → 最后一层过程物：
  - **留下**（默认）；
  - **彻底删除**（不可恢复）。
- 解压侧的回收站档已下线，只有“留下/彻底删除”两档；⑤打包的“其余物”仍可选移入回收站。

### 6.3 其余物

失败或部分完成留下的过程物、按设置收进来的中间物，集中在这里；成功清理与失败保留按清理页档位执行。

## 7. 密码

支持：

- 统一密码（可对所有任务使用）；
- 本次运行手动输入密码（只对本次生效，不落盘）；
- 密码本列表式（一行一个）或映射式（`名称:密码`）；
- 多本密码本，按记住顺序加载；
- 最近成功密码优先、每层尝试上限（默认 10，1–1000）；
- 从同目录说明文件提取候选（默认关）。

密码值与顺序存 `%LOCALAPPDATA%\ArchiveFixer\passwords.txt`（DPAPI 当前用户加密）；换用户/换机/重装系统会解不开。解压侧日志、报告、剪贴板只出现脱敏形态。

「达到密码尝试上限」不是密码错误；把它当“还没试完”处理。

## 8. 引擎

- 内置 7-Zip（`tools\7zip\7z.exe`）与 UnRAR（`tools\unrar\UnRAR.exe`）；
- 可选本机 WinRAR 的 `UnRAR.exe` / `Rar.exe`，程序只检测和调用，**不分发 WinRAR**；
- 引擎优先级在②/⑦页调整，落盘顺序就是生效顺序；
- 填了不存在的工具路径时，本轮设置不落盘并写 WARN；
- 引擎按能力筛选，不因为排第一但不可用而打不开包。

## 9. 空间与并发

- 并发数：1–4，默认 2；普通解压和特定解压共用这个上限；
- 启动前按峰值做空间门，不够不开始，并写清需要多少；
- 运行中周期侦察空间，批末给空间曲线；
- 「空间不足」是运行期开关：只收紧并发/排序，并强制彻底删除过程物；源包按档处理；
- 「全速」已退役，程序不自动升降档。

## 10. 打包

1. ⑤页选文件夹或单个文件；
2. 输入密码（两层相同/不同）；
3. 程序按内容大小切目标 2 或 3 个 7z 加密分卷（内容 < 1 GiB 切 2 卷、≥ 1 GiB 切 3 卷；实际卷数按每卷上限算），再做成一个外层文件：有 WinRAR 用 rar，没有则自动用 7z；
4. 选最终压缩包落点（源旁边/指定位置）；
5. 点「打包…」并在确认框确认两档操作：原包留下/移入其余物；其余物（那几个 7z 分卷）彻底删除（默认）/移入回收站/保留。

内层的几个 7z 分卷会装进同一个外层 RAR/7z；最终产物是一个文件，不是多个 RAR 卷。打包失败/取消不动源包；外层容器生成且校验通过后才按你选的源包/其余物档位处理。WinRAR 不随包分发；没有 WinRAR 时外层自动用 7z。

## 11. 日志、停止、失败

- 任务列表显示状态、原因、大小、耗时和密码状态；
- 日志按级别着色，可导出“本次操作”或全部历史；
- 日志区上方「导出诊断包」生成一个 zip：本次操作的日志、任务事实、失败任务、脱敏设置、工具版本、错误码表和包清单；日志里的错误码可对应到源码位置；
- 失败/取消/部分完成保留最后一层过程物（按③清理方式档位）；
- 「停止后续」在安全点停；「取消当前」立即中断；
- 失败原因会尽量落到具体：密码错、缺卷、损坏、空间不足、安全上限、引擎不可用等。

## 12. 常见限制

- 判不出格式/卷号/缺片时不动，不会猜；
- 内容物不会被自动解开，即使它其实是压缩包；需要手动选中「只解压」；
- 真正的 APK 不碰；
- 分卷源片只链接/保留，不因标准名改源名；
- 危险路径、Windows 保留名、路径过长会在解压前拦截；
- 已知限制与当前缺口以 `docs/开发/检验等级.md` 为准。
