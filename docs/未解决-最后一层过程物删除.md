> 结论先说：当前「留下 / 彻底删除」的选择语义**不按错误处理**；待确认的是最后一层过程物的**落点与呈现方式**。

## 1. 用户模型

```text
原包 -> 过程物 -> 内容物
```

- 原包：用户导入的包，一直在原来的位置，不搬。
- 过程物：解压途中产生的、还能继续解出内容物的中间包。
- 最后一层过程物：链在失败那一层停下来时，那一层要解的内层包。
- 原包操作只在整条链完全成功后发生；失败链不动原包。
- 成功链的过程物由程序按固定规则清掉，用户不选。
- 最后一层过程物只在失败时有用户选择：**留下 / 彻底删除**。

### 用户给出的例子

原包：

```text
111/1111.rar
```

成功解出：

```text
111/1111.rar
111/1111/222.rar
```

继续解出：

```text
111/1111.rar
111/1111/222/333.rar
```

如果 `333.rar` 解压失败，`333.rar` 就是最后一层过程物。

#### 选「留下」

期望：

```text
111/1111/222/333.rar
```

即：最后一层过程物原地不动。

#### 选「彻底删除」

期望先把它放到失败层自己的其余物里：

```text
111/1111/222/其余物/过程物/333.rar
```

再在这个位置彻底删除它。
