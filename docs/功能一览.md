# 功能一览

> 适用版本：ArchiveFixer v0.2.2  
> 最后核对：2026-11-14，代码 HEAD `7be7424d`  
> 定位：当前能力与边界；操作步骤见 `使用说明.md`，设置见 `设置项.md`，内部判据见 `docs/开发/`。

## 1. 识别

- 按文件头魔数识别真实格式，不依赖后缀；覆盖 ZIP / 7Z / RAR4 / RAR5 / GZIP / BZIP2 / XZ / TAR / CAB / ARJ / LZH / Z / Zstandard / LZ4 / RPM / ISO。
- 识别文件头认不出时，按尾部/顺序扫描找内嵌归档；支持视频/图片前缀 + 尾部归档、归档前后有垫数据。
- 媒体前缀完整归档：ZIP 可直读，RAR/7z 可抠取区间后交给引擎；不把普通 MP4/安装器误报为内嵌归档。
- 分卷成员按内容事实 + 名字卷槽 + 同基名兄弟识别；判不出保留原样。
- 后缀状态：正常 / 缺失 / 不匹配 / 多重伪装 / 内嵌归档 / 分卷后缀 / 格式未知。
- 加密状态：RAR/ZIP/7z 读头判加密；读不出按 Unknown，不猜。

## 2. 扫描与内容物

- 导入支持添加文件、添加文件夹、追加、拖放；文件夹可递归扫描。
- 隐藏/系统文件默认不纳入；扫描模式、大小上限可配置。
- 普通内容物（图片、视频、音频、PDF/文档、文本、docx/xlsx/pptx/odt/epub/jar）自动路径不解压、不递归、不改名、不搬、不删。
- 内容识别只走 `ContentAdmission`：普通产物不探测；用户源包或同基名/分卷候选才探测。
- 内容容器默认保护；用户明确导入的容器保留“只解压”强制拆能力。
- 真正的 APK 不打开、不递归、不改名。
- 内容物保留关键词：名字命中即不解、不改名、不搬、不删。
- 4,000 个普通内容物的专项测试要求内容探测次数 <100。

## 3. 后缀与分卷

- 一键处理自动修正可证伪装后缀；手动“智能修正”先预览。
- 分卷按组处理：7z `.001...`、跨盘 ZIP `.z01...zip`、通用 ZIP `.zip.001...`、RAR `.partN`/老编号。
- 缺卷只报缺哪几片，不调引擎、不删片。
- 完整组只解一层；入口层使用逻辑标准名/硬链接，源片保持原名。
- 支持缺卷兄弟文件、短数字卷号、脏卷名、媒体前缀等识别；判不出什么都不做。
- 同基名跨目录可成组；不同族/强锚点冲突不混组。

## 4. 解压与递归

- 双引擎：内置 7-Zip + UnRAR；可选本机 WinRAR；按能力筛选，按优先级排序。
- 统一密码、手动密码、密码本列表/映射、多本密码本、最近成功优先、每层尝试上限。
- 递归解压：最大嵌套层数 1–10，默认 7；每层只解必要的一层。
- 原包/内层包/分卷组/媒体前缀/内嵌 ZIP 都接同一条协调器路径。
- 解压前条目路径预检、资源预算、安全上限；解压后落点校验与结果校验。
- 危险条目、路径穿越、Windows 保留名、路径过长会拦截。
- 输出校验按条目数/总大小核对；不完整不轻易判成功。

## 5. 输出与整理

- 落点：包名 + 同名子文件夹 + 压缩包内容层；不塌缩；指定位置同理。
- 同名冲突：跳过/覆盖/自动重命名/询问；默认自动重命名，绝不静默覆盖。
- 工作区固定 `<目标目录>\.ArchiveFixer.work`。
- 源包：留下（默认）/ 就地彻底删除（成功后）。
- 最后一层过程物：留下（默认）/ 彻底删除。
- 其余物集中与整理；解压侧的回收站档已下线（打包的其余物仍可选移入回收站）。
- 结果归集、部分完成发布、空文件夹清理。

## 6. 并发与空间

- 并发数手动 1–4，默认 2；普通与特定解压共用上限，程序不自动升降档。
- 启动前空间门、运行中空间侦察、批末空间曲线。
- 「空间不足」运行期开关：收紧并发/排序、强制彻底删除过程物，源包按档处理。
- 自动并发实验已暂停，当前不参与调度。

## 7. 打包

- 选文件夹或单文件；单文件旁建同名文件夹后打包，不动源文件。
- 必填密码；两层可相同/不同；密码只存内存、不写设置、不记日志。
- 内层 7z 加密分卷 + 一个外层文件；WinRAR 可用时用 Rar.exe，不可用时自动 7z。
- 最终包落点：源旁边（默认）/ 指定位置。
- 源包/其余物按打包独立档位处理：其余物可保留/移入回收站/彻底删除（默认）；失败/取消不动源包。

## 8. 界面与日志

- 九个页签：任务、解压方式、清理方式、密码、打包、提醒、引擎、设置、说明。
- 任务列表：勾选、全选/反选、大小、状态、原因、密码状态、耗时、输出位置。
- 一键处理确认框：本次落点/源包/过程物档位；可保存为默认、可跳过后续询问。
- 日志按级别着色；导出本次/全部历史；失败保留证据。
- 批量汇总按成功/失败/跳过/部分完成/未处理分档；含空间曲线。
- 任务支持暂停所有、停止当前、继续解、手动操作。

## 9. 明确不做

- 不识别/解压普通内容物，除非用户明确源包或同基名候选。
- 不碰真正的 APK。
- 不自动删除源包；不默认删除失败现场。
- 不把“判不出”当“不是分卷”。
- 不靠物理改名形成第二大步标准名。
- 不自动联网、不写注册表、不把密码明文写日志。
- 不覆盖用户文件；冲突默认自动重命名。
