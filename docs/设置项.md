# 设置项一览

> 这份是**详细版**：README 只留一句"设置项在这儿"。
> 内容与 README 同源（2026-09-26 从 README 搬来）；`data\appsettings.json` 里的字段名就是表里第一列。

## 配置

配置文件：**`<程序目录>\data\appsettings.json`**。首次启动时，若 `data\` 下还没有配置，
会把旧版本放在**程序目录**或 `%AppData%\ArchiveFixer\` 的同名文件复制过来（两个历史位置都认）。
日志与临时文件在同一位置下的 `logs\` / `temp\`；**解压工作区默认是 `<输出盘>\.ArchiveFixer.work`**
（点开头的隐藏目录，2026-09-24 起；填了 `CacheRootDirectory` 则是 `<它>\work`），
用过的根记在 `data\workspace-roots.txt` 里，③「清理与删除」页照这个清单去找残留 ——
默认档下那里通常**什么都没有**（失败 / 取消收尾会把这一单的工作区整份清掉，见「功能」一节）。

> `data\` 不可写时日志会自动退化成"只写屏幕日志"（不弹错、不崩），所以别把程序放进需要提权的目录。

主要配置项：

> ⚠ **这张表是"配置 ↔ 界面 ↔ 行为"的对照**：每一项都标了**界面上有没有入口**。
> 「界面入口」那一列写的是 **2026-09-24 界面重构之后**的位置：界面按功能拆成六个选项卡
> （①任务 ②解压方式 ③清理与删除 ④密码 ⑤打包 ⑥设置）。**2026-09-26 起设置是自动保存的** —— 改哪一项都立刻落盘（底栏那一行会写明"已自动保存"，非法值会写明"为什么先没存"），⛔ 界面上**没有**保存按钮（用户原话："你那个按钮和最下面一个框……都要删除"）。
> 反过来，界面上能改的每一项都**真的接了线**（2026-09-22 专项体检逐项核对过，见 `_tmp\ArchiveFixer\audit-ui.md`）。

| `AutoScanAfterDrop` | ✅ ⑥设置 → 扫描与识别 | 导入后是否**自动识别**。判据是**所有导入入口**（拖拽 / 添加文件 / 添加文件夹），不只拖拽；关掉后用菜单「文件 → 重新扫描」手动触发 |

| `MaxFileSizeLimit` | ✅ ⑥设置 → 扫描与识别 | 单文件大小上限，单位 **MB**（`0` = 不限制，默认）。超过上限的文件不进任务列表 |
| `UnknownFormatAction` | ✅ ⑥设置 → 扫描与识别 | 未知格式：`MarkUnknown` / `Skip` / `TryExtract` |
| `DefaultExtension` | ✅ ⑥设置 → 扫描与识别 | 智能修正的默认目标后缀 |
| `ExtractToOriginalDirectory` / `CustomOutputDirectory` / `KeepArchiveNameFolder` | ✅ ②解压方式 → 落点（二选一） | 输出位置。界面上是二选一的单选（2026-09-24 用户第 13 条删掉了"摊平"两档），落到设置里仍是这三个键（没有新增设置项）；`KeepArchiveNameFolder` 已作废、`Normalize` 里归一成 `true`，旧的 `false` 配置自动迁移 |
| `TerminalLayoutMode` | ✅ ②解压方式 → 终端落法 | `KeepLastFolder`（默认）/ `UseArchiveName` |
| `CollapseRepeatedFolderLayer` | ✅ ②解压方式 → 终端落法 | 场景 B 塌缩：`111\222\名字\名字.rar` → 产物落 `111\222\名字\`（默认开） |
| `UseSpecialExtraction` | ✅ ①任务 →「一键处理」旁边 | **特定解压总开关**（**默认关**，用户 2026-09-24）。关着时 `SpecialExtractionRules` 里写着什么都不参与运算 —— 一键处理与手动「只解压」的行为与加这条功能之前**逐字相同**。①页那个开关的 ToolTip 会列出当前勾上的规则（一条都没勾就提示去②页挑） |
| `SpecialExtractionRules` | ✅ ②解压方式 →「特定解压」 | **启用的特定规则 Id 清单**（默认 `["SingleContentLayer"]`）。归一化只有一处实现（`SpecialExtractionRules.Normalize`）：认不出的 Id **丢掉**、去重、统一写法、按注册表顺序排；`null`（旧配置缺字段）→ 取默认集，**空列表**（用户全关掉）→ 保持空。界面那一栏**按注册表渲染**，加规则不用改 XAML |
| **一键处理的「本次选项」面板**（不是配置键，是运行期覆盖） | ✅ 点「一键处理」时 | 点「一键处理」时先弹**一次**：本次落点二选一 / 指定位置 / 终端落法 / 源包处理，四项默认值都取下面这些设置项的当前值。**不勾「把本次选择存为默认」时 `appsettings.json` 一个字节都不改**；勾了才写回（落点→上面三个键，终端落法→`TerminalLayoutMode`，源包处理→`SourceHandling`）。勾「以后不再询问」只在**本次运行**内生效（不写设置文件）。面板值只是运行期覆盖，路径仍由 `OutputPlacement` 唯一实现推导 |
| `ConflictAction` / `OverwriteMode` | ✅ ⑥设置 → 扫描与识别 / ②解压方式 → 嵌套与覆盖 | `ConflictAction` 管**同名冲突**（`Skip` / `Overwrite` / `AutoRename`（默认）/ `Ask`，解压落位与改名共用一档）。`Ask` 真的会问，而且两条路径都问：**解压落位**弹一次聚合询问；**改名冲突在预览表里逐条确认**（撞名的行出现「冲突选择（询问档）」下拉，没选不放行，也可点「冲突全部自动重命名」），**不选或直接关掉预览窗口都按保守档自动重命名，绝不覆盖**。`OverwriteMode` 是**引擎侧**的覆盖策略：`SkipExisting`（默认，7z `-aos` / UnRAR `-o-`）/ `OverwriteAll`（`-aoa` / `-o+`）/ `AutoRenameExtracted`（`-aou` / `-or`）/ `AutoRenameExisting`（**只有 7-Zip 有 `-aot`**；RAR 包默认走 UnRAR，它没有这一档，实际行为是「跳过已存在文件」—— 界面上已如实标注） |
| `TestBeforeExtract` | ✅ ②解压方式 → 解压前与完成后 | 解压前是否先跑 `7z t`（默认关：开着会让"无密码的包"看起来像卡住） |
| `TryEmptyPasswordFirst` / `UseGlobalPasswordForAllTasks` | ✅ ④密码 | 密码尝试策略 |
| `MaxPasswordAttemptsPerLayer` | ✅ ④密码 | 每层最多试几个密码候选（默认 10，1~1000）；单层与递归内层共用同一个值，改完当场生效 |
| `RememberPasswordList` | ✅ ④密码 | **记住密码列表**（**默认开**）：列表的内容 / 顺序 / 启用状态 / 手工条目 / 备注 + 记住的密码本一起按本机 **DPAPI（机器范围）** 加密存进 `<程序目录>\data\password-list.dat`（跟 Windows 账号无关、不弹框、不写 C 盘）。**关掉 = 既不写也不读**（磁盘上已有的那份**不会被删**），列表退回"只在本次运行内有效"。⚠ 代价：同机任何本机用户都可能解开；换机器 / 重装系统解不开 → **忽略并提示**（不崩、不覆盖、不删），出路是「写回密码本」 |
| `PasswordBookPaths` | ✅ ④密码 | **记住的密码本（有序，可多本）**：启动时按这个顺序逐本合并（只补列表里还没有的密码，跳过墓碑）。界面上可**逐项移除**（只是不再自动加载，磁盘上的文件一个字节都不动；一本都没有时那一组会写明"启动时不会自动加载任何密码本"）。旧配置里的单数字段 `PasswordBookPath` 会在 `Normalize` 里**迁移进这个列表且保留不清**（回退到旧版本时那一边还认得它） |
| `MaxParallelExtractCount` | ✅ ②解压方式 → 并发与空间 | 并发解压数（1~8，**默认 4**）；**真的生效**，不是摆设。默认值由 1 改成 4 的依据是 2026-09-22 的**并行实测**：并发 1→4 吞吐 **3.08×**（保守 2.70×），**4→8 只再快 1.9%**，而单包耗时 6.63→10.91 s（+108%）、整机 CPU 均值 48.7%→72.7% —— 根因是 6 物理核超订（第 1 波 8 个并发单包 11.9–14.2 s，降到 4 个立刻回到 5.9–6.8 s）；正确性三档 36/36 逐字节一致、心跳三档无 >400 ms 卡顿、取消语义 6/6 通过。界面上这一项旁边写着「建议不超过物理核心数（当前检测到 N 核）」，同一个分组里还有「全速」与「按空间算建议」。⚠ 它与 `LowProcessPriority` 是**两个互相独立的旋钮**，改一个不会动另一个。⚠ 并发越高，"同时在盘上的峰值"越大 —— 空间不够时程序会在启动前拦下装不下的任务（状态「磁盘空间不足」） |
| `RunAtFullSpeed` | ✅ ②解压方式 → 并发与空间 | **全速**（默认关）：勾上之后**并发上限直接取"这一批有多少个任务"**（`ResolveMaxParallel` → 等于完全不按并发档排队），没勾时才用 `MaxParallelExtractCount` 那 1~8 个（节流提示「并发已满…」也只在没勾时出现；中途勾上当场放开）。**2026-09-26 第 1 条之前它只是一个界面开关**（点完不落盘、重启就没了 —— 用户原话："我刚刚测试当点击并发操作的时候，这个开关就没有保存"），现在它是**真设置**：改了立刻自动存、重启后还是勾着的。⚠ 它与 `MaxParallelExtractCount` 独立：并发档决定"平时一次跑几个"，全速决定"要不要一直顶满" |
| ~~`DangerousSpaceModeEnabled`~~ | ⛔ **已退役**（2026-09-25 第 32 条） | 原来是"危险模式"开关。用户把"彻底删除其余物"直接做成了 ③页「2 删除操作」的第三档，这一整套（红按钮 / 自测 / 凭证 / 红横幅）随之删除。旧配置里 `true` 会在 `Normalize` 里**一次性迁移**成"源包放入其余物 + 其余物彻底删除"（正是他当初开它的意思），之后一律写回 `false` |
| ~~`DangerModeSelfTestStamp`~~ | ⛔ **已退役**（2026-09-25 第 32 条） | 原自测凭证，随危险模式一起删除；只为读得懂旧配置文件而保留字段，不再参与任何判定 |
| `RestHandlingAfterVerify` | ✅ ③清理与删除 →「2 删除操作」 | **其余物怎么处理**：`Keep`（**默认**，不动其余物）/ `RecycleBin`（移入回收站，可还原）/ `Delete`（**彻底删除，直接省空间**；界面红字 + 选中后常驻一条不可关闭的红色提示）。触发点是「内容物已定稿 + 输出校验通过 + 未取消」；一键处理**留到整条续解链跑完**再做，手动「只解压」当场做。**失败 / 部分完成 / 取消一律不删**（`RestItemPurger` 五道门槛） |
| `LowProcessPriority` | ✅ ⑥设置 → 启动时行为 | **低运行优先级**（默认开）：让本程序与它启动的解压进程让出 CPU / 磁盘优先级。**改完重启程序才生效**（启动时读一次） |
| `OpenOutputFolderWhenDone` | ✅ ②解压方式 → 解压前与完成后 | **定稿完成后在资源管理器里打开输出目录**（默认关）。只在"定稿成功 + 输出校验通过"后打开；失败 / 取消不打开，整批只开一次。只打开文件夹，**不会**把程序窗口置前或最大化（`AGENTS.md` §13 同精神） |
| `RestRemovalDefaultMode` | ✅ ③清理与删除 | 「其余物 / 空文件夹」清理的**默认档**：`RecycleBin`（默认，可从回收站还原）/ `Permanent`（彻底删除）。只是确认框里那个勾选框的默认状态 —— 删除前**永远**先预览 + 确认 |
| `ReportDangerousEntries` | ✅ ②解压方式 → 解压前与完成后 | **危险条目统计**（默认开）：在解压前那一遍条目预检里顺便数出 **22 种**可执行 / 脚本类后缀，把"本包含 N 个可执行 / 脚本类条目"写进**任务详情窗口与失败清单**。**只提示、绝不阻断** |
| `EnginePriority` | ✅ ②解压方式 → 引擎 | **引擎优先级**（默认 `["winrar","sevenzip"]`）。规则是**先按能力筛、再用优先级做 tiebreaker**，不可用的引擎直接跳过 —— 排第一但没装不会导致打不开包。界面只能上移/下移；落盘的顺序就是生效顺序（点「保存设置」时立刻推给引擎层，不必重启） |
| `CustomSevenZipExePath` / `CustomUnRarExePath` | ✅ ②解压方式 → 引擎 | 自选外部工具路径。**留空 = 自动**（7z：程序内置 `tools\7zip`；UnRAR：用户自选 → 已装 WinRAR 目录 → 内置 `tools\unrar`）。⚠ 填了一个**不存在**的文件时，自动保存会**先不落盘**并在底栏说明改法（以前是"设置已保存"+ 静默丢弃这一格 —— 有测试钉住现在不会） |
| `CustomRarExePath` | ✅ ②解压方式 → 引擎 | **打包**做外层 rar 时用的 `Rar.exe`（2026-09-23 加的界面入口）。⚠ 它指向的是**你自己安装 / 下载的 WinRAR** 里的那一份：程序只检测与调用，**绝不随包分发**（WinRAR 是共享软件）。留空 = 自动用本机已装 WinRAR 目录里的那一份；填了不存在的文件同样**拦在保存之前**。**没装 WinRAR 时打包照样能用** —— 外层会自动改用 7z（产物 `源名.7z`，见下面四个 `Pack*` 项与 §打包） |
| `PackTargetMode` | ✅ ⑤打包 → 确认弹窗 | **打包的最终产物落在哪**：`Local`（**默认**，"本地" = 源文件夹/源文件**旁边**）/ `Custom`（指定位置，配 `PackCustomOutputDirectory`）。⚠ 它与解压侧的落点设置**完全独立**（用户原话"两者绝对不能同步"）；弹窗里选一次就记下来，下次打开弹窗还是这一套 |
| `PackCustomOutputDirectory` | ✅ ⑤打包 → 确认弹窗 | `PackTargetMode = Custom` 时用的目录；留空 = 回落"本地" |
| `PackSourceHandling` | ✅ ⑤打包 → 确认弹窗 | 打包的**原包操作**：`KeepInPlace`（**默认**，源一个字节都不碰）/ `MoveToRest`（打包成功后把源搬进"其余物"那个文件夹）。⚠ 与 ③页的 `SourceHandling` **各存各的** |
| `PackRestHandling` | ✅ ⑤打包 → 确认弹窗 | 打包的**其余物操作**（其余物 = 装 7z 分卷的文件夹；单文件时还有那个临时建的同名文件夹）：`Keep` / `RecycleBin` / `Delete`（**默认彻底删除** —— 用户原话"这个对用户来说一点用没有"）。触发点 = **外层容器生成 + 校验通过之后**；失败 / 取消一个字节不动；**做不出外层时这一档不执行**（那里面装着这次唯一的结果）。⚠ 与 ③页的 `RestHandlingAfterVerify` **各存各的**；危险组合（原包移入其余物 + 其余物要删）在弹窗里**当场红字警告** |
| `KeepBrokenFiles` | ✅ ②解压方式 → 引擎 | **保留受损的文件**（默认关）：校验和错误的半成品**留不留**。⚠ 只对 RAR 引擎（UnRAR）生效 —— 7-Zip **没有** `-kb` 这个开关（实测 `Unknown switch: -kb`，退出码 7），它本来就保留半成品。⚠ 它与成败判定**无关**：留着半个文件仍然是"失败 / 部分完成" |
| `RecursionMode` / `MaxRecursionDepth` | ✅ ②解压方式 → 嵌套与覆盖 | 递归模式（默认 `SingleLayer`）与最大层数（1~10，**默认 5**）；改完当场生效，不必重启。⚠ 这一格就是**一键处理每一批解几轮**的那个数字（`OneClickCoordinator.RoundLimit`，天花板 10 = 不变量 8）—— ⛔ 程序里没有第二套轮数，界面写 5 就跑 5 轮；到顶会把剩下的内层包加进列表并勾好 + 给「继续解」按钮。2026-09-26 用户把默认从 10 降到 5（"用户有需要自己会改的"），理由见 `docs/使用说明.md` §10.1.4 |
| `CollectResultsToDirectory` / `CollectTargetDirectory` | ✅ ②解压方式 → 解压前与完成后 | 结果归集开关与目标目录 |
| `SourceHandling` | ✅ ③清理与删除 →「1 源包操作」 | 怎么处理源包：`KeepInPlace`（**默认**，"原来的位置不动"，一个字节都不搬）/ `MoveToRest`（放入其余物当中）。**一键处理与手动「只解压」读的是同一档**（用户 2026-09-22 版本二 + 2026-09-25 第 32 条"手动档的操作就和选项卡里面的一致"）。⚠ 读不懂的值一律回落 `KeepInPlace`（兜底只能落在"什么都不做"上） |
| ~~`DeleteSourceAfterExtract`~~ | ⛔ **已退役**（2026-09-25 第 32 条） | 原来那个"手动「只解压」成功后删源包"的独立开关 —— 手动档不再有自己的删除开关，统一读 `SourceHandling` + `RestHandlingAfterVerify`。旧值 `true` 在 `Normalize` 里迁移成"放入其余物 + 移入回收站"（可还原的那一档，宁可少删） |
| `RemindBeforeExtract` | ✅ ③清理与删除 | **解压前的提醒**（**默认开**，用户 2026-09-24 第 15 条要求可关）：每次解压前扫一遍源目录，列出"可能的无用物"与"一个可用密码都没有"的包。关掉 = **不扫也不弹**，直接开始 |
| `EnableSidecarPassword` | ✅ ④密码 | 从压缩包同目录的说明文件里提取密码候选（默认关） |
