# 设置项一览（v0.2.4）

> 适用版本：ArchiveFixer v0.2.4
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 数据源：`Models/AppSettings.cs` 的字段、默认值与 `Normalize`；界面入口来自 `Views/Tabs/*.xaml`。  
> 代码与本文冲突时以代码为准；旧版本的键若仍能读入但不生效，会标“已退役”。

## 0. 位置与生效

- 配置文件：`%LOCALAPPDATA%\ArchiveFixer\appsettings.json`（固定，不可改根）。
- 密码：`passwords.txt`（DPAPI 当前用户加密）；元数据：`passwords.meta.json`。
- 日志：同目录 `logs\`；临时：`temp\`。
- 工作区：`<目标目录>\.ArchiveFixer.work`（不可配置）。
- 设置自动保存；界面没有保存按钮。设置项修改后立即生效或在下一次操作生效，表中注明。

## 1. 扫描与导入

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `RecursiveScan` | `true` | 底层固定；文件夹扫描递归 |
| `AutoScanAfterDrop` | `true` | 底层固定；所有导入入口导入后自动识别 |
| `ScanMode` | `ScanAllFiles` | 底层固定；`ScanAllFiles`/`ScanKnownArchiveExtensions`/`ScanSuspiciousFiles` |
| `UnknownFormatAction` | `MarkUnknown` | 底层固定；`MarkUnknown`/`Skip`/`TryExtract` |
| `DefaultExtension` | `.7z` | 底层；智能修正的默认目标后缀 |
| `IncludeHiddenFiles` | `false` | ⑧设置 → 扫描与识别 |
| `IncludeSystemFiles` | `false` | ⑧设置 → 扫描与识别 |
| `MaxFileSizeLimit` | `0`（MB，0=不限） | ⑧设置 → 扫描与识别；只管扫描收不收，不等于解压安全上限 |

## 2. 落点与输出

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `ExtractToOriginalDirectory` | `true` | ①任务输出位置 / ②解压方式落点；与 `CustomOutputDirectory` 同一真值 |
| `CustomOutputDirectory` | 空 | 指定输出根 |
| `PlacementMode` | `null` | 旧持久化兼容字段；实际落点由上面两项推导，不单独作为入口 |
| `KeepArchiveNameFolder` | `true` | 底层固定；包名一层永远保留 |
| `ConflictAction` | `AutoRename` | ②解压方式；`Skip`/`Overwrite`/`AutoRename`/`Ask`；默认自动重命名，不静默覆盖 |
| `OverwriteMode` | `AutoRenameExisting`（`CreateDefault`/`Normalize` 后的系统值） | 引擎侧覆盖策略；`SkipExisting`/`OverwriteAll`/`AutoRenameExtracted`/`AutoRenameExisting` |
| `CollectResultsToDirectory` | `false` | ⑥提醒 → 解压前与完成后；结果归集开关 |
| `CollectTargetDirectory` | 空 | 归集目标 |

## 3. 解压、层数与引擎

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `MaxRecursionDepth` | `7` | ②解压方式 → 嵌套与覆盖；范围 1–10，一键续解轮数同此值 |
| `TestBeforeExtract` | `false` | 底层；解压前是否跑 `7z t` |
| `PreviewBeforeRename` | `true` | 底层；手动改名先预览 |
| `MaxParallelExtractCount` | `2` | ②解压方式 → 并发与空间；范围 1–4，普通/特定共用 |
| `RunAtFullSpeed` | `false` | 已退役；旧键只为兼容，不再影响调度 |
| `ConcurrencyOverride` | `0`（仅测试/排障） | 底层；无头夹具固定并发，不暴露给用户 |
| `EnginePriority` | `["winrar","sevenzip"]` | ②解压方式 → 引擎；按能力筛选后用顺序 tiebreaker |
| `CustomSevenZipExePath` | 空（内置 `tools\7zip`） | ②/⑦引擎 |
| `CustomUnRarExePath` | 空（已装 WinRAR → 内置 `tools\unrar`） | ②/⑦引擎 |
| `CustomRarExePath` | 空（自动找本机 WinRAR） | ②/⑦引擎；仅打包外层 rar 使用，不随包分发 |
| `KeepBrokenFiles` | `false` | ②/⑦引擎；只对 UnRAR 生效 |
| `AssembleSplitVolumesFromContainer` | `true` | 底层；容器里的首卷自动接同目录后续卷；判不准不动 |

## 4. 安全、日志与提醒

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `EnableLog` | `true` | ⑧设置 → 日志；关掉只停文件日志，屏幕仍显示 |

| `ReportDangerousEntries` | `true` | 底层；统计可执行/脚本条目，只提示不阻断 |
| `MaxSingleExtractedFileGiB` | `64` | ⑧设置 → 安全上限；1–4096 GiB |
| `MaxExtractedTotalGiB` | `512` | ⑧设置 → 安全上限；1–4096，且不小于单文件上限 |
| `MaxExtractedFileCount` | `200000` | ⑧设置 → 安全上限；1–50,000,000 |
| `MaxExtractionRatio` | `1000` | ⑧设置 → 安全上限；1–1,000,000 倍，超了按压缩炸弹拒绝 |
| `RemindBeforeExtract` | `true` | ⑥提醒；解压前提醒 |
| `RemindJunkAfterImport` | `true` | 底层固定；导入后无用物提示 |
| `SkipOneClickConfirm` | `false` | ⑥提醒；一键处理前不再弹确认框 |
| `RememberLastOutputDirectory` | `true` | 底层固定 |
| `LastLogExportDirectory` | 空 | 日志导出对话框上次目录 |

| `LowProcessPriority` | `false` | 底层固定；不再提供界面开关 |

## 5. 清理与过程物

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `SourceHandling` | `KeepInPlace` | ③清理方式 → 源包操作；`KeepInPlace`/`DeleteInPlace`（成功+校验后才删；`MoveToRest` 已删除） |
| `RestHandlingAfterVerify` | `Keep` | ③清理方式 → 最后一层过程物；`Keep`/`Delete`（回收站档已下线） |
| `KeepFailedWorkspace` | `false` | 底层固定；失败/取消默认清工作区 |
| `PartialPublishEnabled` | `false` | 底层；部分完成发布，默认关 |
| `UseSpecificExtraction` | `false` | ①任务 → 特定解压；独立整理模式 |
| `ContentKeepKeywords` | 空列表 | ②解压方式 → 内容物保留关键词；包含即命中，不做通配/正则 |

## 6. 密码

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `TryEmptyPasswordFirst` | `true` | ④密码 |
| `UseGlobalPasswordForAllTasks` | `true` | ④密码；输入的统一密码仅对本批次生效，不保存，重启后清空 |
| `MaxPasswordAttemptsPerLayer` | `10` | ④密码；1–1000，每层共用 |

## 7. 打包（与解压设置完全独立）

| 字段 | 默认 | 界面/说明 |
|---|---:|---|
| `PackTargetMode` | `Local` | ⑤打包；`Local`（源旁边）/`Custom` |
| `PackCustomOutputDirectory` | 空 | ⑤打包指定位置 |
| `PackSourceHandling` | `KeepInPlace` | ⑤打包确认框；`KeepInPlace`/`MoveToRest` |
| `PackRestHandling` | `Delete` | ⑤打包；`Keep`/`RecycleBin`/`Delete`（仅外层生成+校验后执行；打包侧回收站仍可用，与解压侧无关） |

## 8. 已退役/内部字段

- `RunAtFullSpeed`、`TerminalLayoutMode`、`CollapseRepeatedFolderLayer`、`RecursionMode`、`DeleteSourceAfterExtract`、`RestRemovalDefaultMode`、`DangerousSpaceModeEnabled`、`DangerModeSelfTestStamp`：旧版本键，读入后不生效或被 `Normalize` 迁移。
- `RecursionDefaultUnifiedToTen`：一次性迁移标记，不是用户设置。
- `UnknownSettings`：保留未知旧键，避免旧配置文件丢失。
- `OmitMiddleContinuationLayers`：旧续解省略中间层设置，已移除；行为固定为当前续解规则。

> 任何设置项的实际行为以其消费点代码为准；新增/改名设置时同步更新本表和 `docs/使用说明.md`。
