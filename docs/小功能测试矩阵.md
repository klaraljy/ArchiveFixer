## 2. Pairwise 参数

后续界面/设置组合测试用下列参数做 pairwise，不做全排列：

```text
处理模式：普通一键 / 特定解压 / 手动只解压
源包处理：留下 / 彻底删除
其余物：留下 / 彻底删除
嵌套：单层 / 多层
分卷：无 / 标准分卷组
落点：包名子目录 / 指定位置
冲突：自动改名 / 跳过 / 覆盖
密码：无 / 已知 / 错误
空间不足：关 / 开
```

生成用例时至少保证：

- 每个参数每个取值出现；
- 任意两个参数的取值组合至少出现一次；
- 特定解压与“源包处理=彻底删除”必须出现（现有用例已钉住源包永不删）；
- 空间不足 + 失败 + 源包处理 必须出现（现有用例已钉住不删源包）。

## 3. Pairwise 自动化

`PairwiseMatrixTests` 已实现通用 pairwise 生成器，当前参数全排列为 192 组，测试会断言：

- 每个参数每个取值出现；
- 任意两个参数的所有取值组合至少出现一次；
- 用例数明显少于全排列；
- `特定解压 + 源包彻底删除`、`空间不足 + 源包彻底删除`、`标准分卷 + 多层嵌套` 都被覆盖。

具体业务结果仍由特定解压 / 源包 / 其余物 / 空间不足各自的执行用例负责，不用 pairwise 表代替断言。
