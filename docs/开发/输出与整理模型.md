# 输出与整理模型

> 适用版本：ArchiveFixer v0.2.4  
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 状态：现行。旧需求/决策记录见 `docs/历史/旧开发文档/输出与整理模型-旧版.md`。

## 1. 落点

两种模式：

- 原路径：内容物落在源包所在目录下的同名子文件夹；
- 指定位置：内容物落在指定根下的同名子文件夹。

固定规则：

- 不塌缩；
- 包名一层始终保留；
- 落点由 `OutputPlacement` 唯一推导；
- 工作区固定 `<目标目录>\.ArchiveFixer.work`；
- 缺目标目录如实报错，不回落程序目录/C 盘/`%TEMP%`/源卷根。

## 2. 两阶段

```text
解压 → stage（暂存）
→ 校验/定稿计划 → commit（搬到最终落点）
```

- stage 里是中间产物；
- commit 前做路径/冲突/空间/完整性检查；
- 失败/取消保留现场按档，不把半成品当成品。

## 3. 冲突

`ConflictAction`：

- `Skip`：跳过；
- `Overwrite`：覆盖（需用户明确）；
- `AutoRename`（默认）：自动重命名，绝不静默覆盖；
- `Ask`：询问。

`OverwriteMode` 是引擎侧覆盖策略；与落点冲突策略分开。

## 4. 源包

`SourceHandling`：

- `KeepInPlace`（默认）：一个字节不搬、不删；
- `DeleteInPlace`：解压成功 + 输出校验通过后，从原位置彻底删除；
- 旧 `MoveToRest` 已删除；源包不搬进其余物。

失败/部分完成/取消：源包不动。

## 5. 过程物/其余物

- 过程物 = 解压中产生的中间包/片；
- 成功链上的过程物按固定规则清理；
- 失败/部分完成时，**最后一层过程物**按 `RestHandlingAfterVerify`：
  - `Keep`（默认）；
  - `Delete`（彻底删除，不可恢复）；
- 回收站档已下线；
- 手工清理其余物是用户显式动作，仍需确认和路径闸门。

## 6. 归集/空目录

- `CollectResultsToDirectory` 可把产物归集到指定目录；
- 空文件夹清理只删空目录；
- 自建目标目录若整批没产出可收掉；用户原有目录不动。

## 7. 工作区

- 每个目标目录一个 `.ArchiveFixer.work`；
- 成功链完成后清理；
- 失败/取消是否保留由 `KeepFailedWorkspace`（固定 false）和档位决定；
- 不把工作区放源卷根/程序目录/系统临时目录。

## 8. 不变量

- 不覆盖用户文件；
- 不把源包算进内容物；
- 不把内容物当过程物删；
- 不把半套分卷当完整组；
- 判不出 ⇒ 不动。
