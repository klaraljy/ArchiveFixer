# 架构总览

> 适用版本：ArchiveFixer v0.2.3  
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 状态：现行。按当前源码目录与入口类整理，不引用旧框架。

## 1. 形态

- 单进程 WPF 应用，单项目 `src/ArchiveFixer/ArchiveFixer.csproj`；
- 目录分层是**命名空间/工程约束**，不是独立程序集：
  - Domain/Detection/Engines/Password/Extraction/Security/Storage/Packing 不得引用 WPF；
  - ViewModels/Views 负责 UI 编排与展示；
  - Services/Storage 提供路径、日志、设置、清理、调度、空间等基础设施。
- 入口：`App.xaml.cs` → `MainWindow.xaml.cs` → `MainViewModel`。
- 所有设置、密码、日志固定在 `%LOCALAPPDATA%\ArchiveFixer`；工作区在目标目录的 `.ArchiveFixer.work`。

## 2. 运行时分层

```text
WPF Views / Tabs
  ↓ data binding / commands
MainViewModel
  ├─ ScanCoordinator        导入、扫描、识别
  ├─ OneClickCoordinator    一轮/多轮、续解、第二大步、批末
  ├─ RenameCoordinator      手动/自动后缀修正
  ├─ PackingViewModel       打包页
  └─ SettingsViewModel      设置页
        ↓
ExtractionCoordinator（partial 分组）
  ├─ 调度/空间/并发
  ├─ 单任务执行/密码/引擎
  ├─ 递归/分卷/交接
  ├─ 定稿/落点/校验
  └─ 源包/其余物/工作区/批末
        ↓
Detection / Extraction / Engines / Password / Security / Storage
```

## 3. 关键模块

### 3.1 导入与识别

- `ViewModels/ScanCoordinator`：添加文件/文件夹、追加、扫描、任务列表。
- `Services/FileScanService`：文件枚举与任务构造。
- `Services/ArchiveDetectService`：格式、加密、内嵌归档、尾部扫描。
- `Detection/FileNature`：`FileNatureCard` 唯一底层事实（格式、分卷身份、名字线索、媒体结构、物理身份）。
- `Detection/ContentAdmission`：内容探测准入；`FileContentProbe` 只在这里被需要时调用。
- `Detection/FirstStepFileLedger`：第一大步产物/交接账本，第二大步候选唯一来源。

### 3.2 一轮与多轮

- `ViewModels/OneClickCoordinator`：
  - 轮循环（`MaxRecursionDepth` 决定轮数上限）；
  - 第一大步扫描/解压；
  - 产物扫描 `CollectInnerLayersAsync`（后台）；
  - 轮判定 `RoundProductClassifier`；
  - 第二大步组分析/入口层/只解一层；
  - 批末源包/其余物/汇总。
- `Extraction/RoundProductClassifier`：把本轮产物分为单一包/分卷/内容物，决定下一轮从哪一步开始。
- `Extraction/RecursiveExtractor`：递归层内层包发现与解压；内容容器/APK 闸门。
- `Extraction/VolumeCandidateDiscovery`：同基名/分卷候选组分析。
- `Extraction/VolumeStep/*`：三族 boundary resolver / prepared / facts。

### 3.3 单任务执行

- `ExtractionCoordinator.ExtractEntryStep`：一键/手动入口。
- `ExtractTaskMainStep`：任务生命周期主段（跳过/改名/试密码/解压/失败/终态）。
- `EmbeddedZipStep`：媒体前缀/内嵌 ZIP 直读或抠取。
- `PostProcessSuccessStep`：定稿后的校验、工作区清理、输出目录打开。
- `Recursion.cs` / `RecursiveLayerReclaimStep`：递归执行与层回收。
- `PlacementStep` / `ResultFinalizer` / `OutputVerifier`：落点、定稿、校验。
- `RestHandlingStep` / `SourceCleanupService` / `RestItemPurger`：源包与其余物。

### 3.4 分卷

- `Detection/VolumeNumberFromContent`：RAR/ZIP 卷号/首卷/成员证据。
- `Detection/VolumeGroupResolver`、`VolumePiecesFromCards`：组识别/证据；`Extraction/StandardNameFastPath`：标准名快通道。
- `Extraction/VolumeGroupEntryLayer`：入口层；标准名硬链接/移动。
- `Extraction/SplitVolumeAssembler`：容器内首卷 + 同目录后续卷拼装。
- `Extraction/VolumeProbeVerifier`：只读试开。
- `ViewModels/ExtractionCoordinator.Volume*.cs`：交接、组收集、ledger、repair、entry。

### 3.5 引擎、密码、打包、安全

- `Engines/`：7-Zip / UnRAR 进程、退出码、能力、选择器、WinRAR 兜底。
- `Password/` + `Services/PasswordCandidatesStep` + `Storage/PasswordListStore`：密码本、候选、DPAPI 存储。
- `Packing/`：打包计划、执行、校验、清理。
- `Security/`：路径闸门、路径长度、资源预算、内容容器保护。
- `Storage/`：空间门、空间趋势、任务调度、源快照、回收站/清理、工作区。

## 4. 数据流

```text
用户导入
→ ScanCoordinator/FileScanService 建 ArchiveTask
→ ArchiveDetectService + FileNature 出事实
→ OneClick/ExtractionCoordinator 调度
→ 解压到 stage → 定稿到落点 → 输出校验
→ 递归/第二轮 → 组/内容物
→ 源包/过程物/其余物按设置处理
→ 批末汇总/日志
```

关键事实链：

- 任务路径：`OriginalPath`（导入时） / `CurrentPath`（当前真实路径）；
- 终态：`TaskOutcome`（Pending/Succeeded/PartiallyCompleted/Failed/Cancelled/Skipped）；
- 分卷：`VolumeFacts` / `PreparedVolumeGroup` / `FirstStepFileLedger`；
- 内容：`FileNatureCard` + `FileContentProbe` + `ContentAdmission`；
- 定稿：`FinalizePlan` / `OutputVerification` / `OutputPath`。

## 5. UI 线程与后台

- 解压主体、目录枚举、产物扫描在后台/异步执行；
- UI 只负责命令、任务表、日志与确认框；
- `UiActivity.Mark` 只写 UI 阶段；后台用 `MarkBackground`；
- `UiResponsivenessMonitor` 记录 UI 停顿；后台标记不得覆盖 UI 阶段。

## 6. 约束

- 不新增运行时 NuGet 依赖、不升级 TFMs；
- 不走第二套判据：内容事实走 `FileNature`/`ContentAdmission`，分卷事实走账本/族 resolver；
- 不按文件名/样本名加特例；
- 不可逆动作先过 `archivefixer-unsafe-paths` 闸门。
