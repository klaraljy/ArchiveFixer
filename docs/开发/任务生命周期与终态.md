# 任务生命周期与终态

> 适用版本：ArchiveFixer v0.2.4
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 状态：现行。依据 `ArchiveTask`、`TaskOutcomeClassifier`、`ExtractionCoordinator.*`、`OneClickCoordinator`。

## 1. 一个任务从哪来

`ScanCoordinator` / `FileScanService` 导入文件或文件夹，创建 `ArchiveTask`：

- `OriginalPath`：导入时路径，不再改；
- `CurrentPath`：当前真实路径，后缀/分卷/源包移动后更新；
- `TaskId`：内存中的任务身份；
- `Index`、`FileName`、`DirectoryPath`、`SourceSizeBytes` 等 UI/事实字段。

任务列表可以有重复路径的不同任务；判断“同一份文件”用 `FileIdentity`（卷序列号 + 文件索引），不是路径。

## 2. 扫描与识别

```text
导入 → FileScanService 枚举
→ ArchiveDetectService 识别格式/加密/内嵌
→ FileNature.Inspect 出底层卡
→ 任务状态进入待处理
```

识别认不出不会阻塞导入；任务仍可在列表里，由一键/手动处理时按事实决定。

## 3. 一键处理的一轮

`OneClickCoordinator.RunPipelineAsync`：

1. 取本轮目标（只处理还在列表里的任务）；
2. 扫描/识别本轮新任务；
3. 记录解压前已有文件（避免把旁边旧包当产物）；
4. `StartExtractForOneClickAsync` 执行第一大步/后续轮；
5. `FinalizeContentGroups` 回填组级结论；
6. `UpdateSummary`；
7. `CollectInnerLayersAsync` 扫本轮产物（后台）；
8. `RoundProductClassifier` 判下一轮：单一包 / 分卷 / 内容物；
9. 若还有内层包：加任务、进入下一轮；到达层数上限则保留“继续解”；
10. 批末处理源包/其余物/汇总。

## 4. 单任务执行

`ExtractionCoordinator.RunScheduledTaskAsync` → `ProcessExtractTaskAsync`：

- 清提示字段；
- 内容物/APK/分卷成员的早退分支；
- 伪装后缀修正；
- 进入 `ExtractSingleTaskAsync`：
  - 建 stage/工作区；
  - 密码候选/试开；
  - 引擎解压（含 WinRAR 兜底）；
  - 递归层；
  - 定稿/落点/输出校验；
  - 源包/过程物/其余物；
  - 写状态与 `TaskOutcome`。

失败/取消不写成功；定稿失败、校验失败、越界、超预算单独落原因。

## 5. 机器终态

`TaskOutcome`（`ArchiveTask.Outcome`）只有：

| 值 | 含义 | 是否允许后续不可逆动作 |
|---|---|---|
| `Pending` | 还没有结论 | 否 |
| `Succeeded` | 产物定稿、输出校验通过、源包处理无问题 | 是（唯一成功档） |
| `PartiallyCompleted` | 做了一部分（源包/递归停在需用户决定处） | 否 |
| `Failed` | 失败/校验不过/越界/超预算/密码试完 | 否 |
| `Cancelled` | 用户取消 | 否 |
| `Skipped` | 非压缩包/冲突跳过 | 否 |

`TaskReason` 是原因（缺卷/校验/引擎/密码/路径/源变化/跳过/取消/最终组不完整/损坏），只解释“为什么”，不替代 `TaskOutcome`。

## 6. 状态文案与终态分离

- `StatusText` 只做显示（等待扫描、扫描中、已识别、解压成功、密码错误、文件损坏、分卷缺失、部分完成、跳过、取消等）；
- 删除/搬源/续解/清理只读 `TaskOutcome`，⛔ 不拿中文状态字符串当判据；
- 批末汇总/①页分桶统一走 `TaskOutcomeClassifier`，避免“①页算失败、汇总算未处理”。

## 7. 分卷组的生命周期

- 第一大步：分卷成员/首片/名字证据 ⇒ 只登记交接，不解；
- 第二大步：完整组 → 入口层标准名 → 只解一层；
- 成功：组 owner 落终态，跟随卷/被消费片按组结账；
- 缺片/判不出：保留原片，不调引擎；
- 源包/过程物处理只按组结论和用户档，不按单行状态。

## 8. 批末

- 汇总成功/失败/跳过/部分完成/未处理；
- 源包按 SourceHandling；
- 最后一层过程物按 RestHandling；
- 成功链过程物清理；
- 工作区空壳/残留清理；
- 有剩余内层包且到层数上限 ⇒ “继续解”计数。

## 9. 禁止

- 用 `StatusText` 字符串代替 `TaskOutcome` 做删除/续解判据；
- 在失败/取消/部分完成上删源包；
- 把“判不出”写成成功；
- 同一任务重复加结果/重复解同一组。
