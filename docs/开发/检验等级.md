# 检验等级（L0–L6）

> 适用版本：ArchiveFixer v0.2.2  
> 最后核对：2026-11-11，代码 HEAD `23acb074`  
> 状态：现行。旧缺口详情见 `docs/历史/旧开发文档/检验等级-旧版.md`；当前缺口汇总见 `当前缺口与风险.md`。

## 0. 原则

每一级都是一道闸门；**闸门没有答案时，兜底落在“什么都不做”**。  
不可逆动作（删源、搬源、永久删除）只允许在 L4 可证完整 + L5 收尾复核通过 + 未取消 + 属于本任务时发生。

## 1. 阶梯

| 等级 | 目的 | 机器事实 | 唯一出口 | 判不出 |
|---|---|---|---|---|
| L0 识别 | 是什么格式、认不认得 | `ArchiveTask.IsArchive` / `DetectedFormat` / `DetectResult` / 加密状态 | `ArchiveDetectService.DetectAsync` + 解压侧格式闸门 | 格式未知且没开试解 ⇒ 跳过，不写盘；试列失败同样跳过 |
| L1 解前 | 挡住不可能/伤别处 | 源快照、缺卷、路径安全、资源预算、空间门 | `SourceFileSnapshot`、`ArchivePathGuard`、`ResourceBudget`、`SpaceGate`/`ExtractionScheduler` | 缺卷报缺；越界拒绝；超预算拒绝；空间不够延后/标 blocked |
| L2 解后 | 产物落在正确位置且非空 | `FindLandingViolation`、`OutputVerifier.Measure`、`OutputVerificationResult` | `RecursiveExtractor.FindLandingViolation` / `OutputVerifier` | 越界/空/全 0 字节 ⇒ 失败，不定稿 |
| L3 清单核对 | 有可信清单才逐条对账 | `ArchiveListResult`、`LayerManifest` | `ChainManifestResolver.Resolve` + `OutputVerifier.Verify` | 没有可信清单 ⇒ 只做 L2 底线校验，标 `ManifestCrossChecked=false` 并说明原因 |
| L4 完整性 | 能否证明完整 | `OutputVerificationOutcome` + `ManifestCrossChecked` + 缺卷 | `ResultCompletenessClassifier.Classify` | `Undeterminable` ⇒ 不删源、不搬源；成果保留 |
| L5 收尾复核 | 定稿前后再确认 | 事后预算、`StageCommitResult` | `PostProcessSuccessStep` / `RunPostProcessWork` | 不通过 ⇒ 失败、不定稿、源包不动 |
| L6 删除闸门 | 删/搬源前查全部结论 | `TaskOutcome` + L4 裁决 + `cancelled` + 归属 + 路径根 | `RestItemPurger`、`PurgeLayerSourcePackage`、链尾搬源/其余物 | 任一不成立 ⇒ 不动，写 WARN 点明哪条拦下 |

## 2. 红线

1. L4 不是 `Complete` ⇒ 不删源、不搬源；
2. 判不出完整性不改变产出，只阻止删/搬；
3. 结论如实写“无法确认完整性”，不写成“校验通过/失败”；
4. 枚举默认值 = `Undeterminable`，漏赋值只会更保守。

## 3. 当前实现注意

- `TaskOutcome` 是机器终态，`StatusText` 只显示；删除/续解/清理只读终态。
- 清单不可信时，L2 底线校验仍在；不要把 L2 通过当 L4 完整。
- 成功后工作区清理、过程物处理、源包处理是三条独立路径，各自有闸门。
- 具体当前限制/缺口见 `当前缺口与风险.md`，不在本文复制第二份。
