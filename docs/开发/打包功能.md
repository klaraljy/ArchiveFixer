# 打包功能

> 适用版本：ArchiveFixer v0.2.4  
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 状态：现行。旧实施记录/日期见 `docs/历史/旧开发文档/打包功能-旧版.md`。

## 1. 输入

- 选一个文件夹，或选一个文件；
- 选文件时程序在它旁边建同名文件夹，把文件放进去（不动源文件），再按文件夹打包；
- 密码必填；两层密码可相同（默认）或不同；
- 外层固定为一个文件：本机有 Rar.exe 时用 rar，没有时自动用 7z；界面不再让用户选外层容器；
- 最终包落点：源旁边（默认）或指定位置。

## 2. 流程

```text
校验源/落点/空间
→ 生成内层 7z 加密分卷（按内容大小算卷数/每卷上限）
→ 做成一个外层 rar（无 Rar.exe 时为一个外层 7z）
→ 校验外层
→ 按 PackSourceHandling / PackRestHandling 处理源与其余物
```

- 7z 分卷：内容 < 1 GiB 目标 2 卷，≥ 1 GiB 目标 3 卷；每卷上限向上取整 MiB；实际卷数按上限算。
- 外层 rar 需要本机 `Rar.exe`；没有则自动改用 7z（界面显示实际产物名，不写“.rar”骗人）。
- 最终产物始终是一个外层文件；内层分卷只是它的内容。
- 密码只存在内存，不写设置、不记日志；“复制密码”是用户显式动作。

## 3. 落点/命名

- 最终包以源名命名；重名自动让位 `源名(1).rar/.7z`，绝不覆盖。
- 内层 7z 分卷直接落在落点目录里；`其余物`就是那几个分卷文件，不再另套文件夹。
- 目标目录/落点由 `PackingPaths` 统一计算，界面摘要与实际产物必须一致。
- 与解压侧落点设置完全独立。

## 4. 源包/其余物

- `PackSourceHandling`：`KeepInPlace`（默认）/ `MoveToRest`；
- `PackRestHandling`：`Keep` / `RecycleBin` / `Delete`（默认 Delete）；
- 只有外层生成 + 校验通过后才执行；失败/取消不动源。

## 5. 安全/失败

- 不会在确认前创建目标目录；
- 源/目标同路径、空间不足、工具不可用会拦下；
- 外部进程只杀自己启动的 PID；
- 失败/取消保留现场；源文件一个字节不动。
