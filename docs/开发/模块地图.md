### 3.5 ExtractionCoordinator 的 Step partial

`ExtractionCoordinator` 主文件（+ `Recursion` / `Source`）只保留字段、构造与公开入口；各阶段按 partial 分文件（文件名 = 阶段名）：

- 批首/批末：`BatchReminderStep`（批前提醒/确认框）、`BatchSummaryStep`（批末汇总）、`VolumeNameNormalizeStep`（批首改名归一 + 任务表同步）、`ExtractionScheduleStep`（空间体检/趋势/调度计划/空间闸门/多层风险/批级上限）、`LogCaptureStep`（任务级日志捕获/摘要行/批清账）。
- 入口/主流程：`ExtractEntryStep`（手动/一键解压入口 + 核心批流程）、`ExtractTaskMainStep`（调度执行/单任务处理/解压主体）。
- 递归/终态：`RecursionOutcomeStep`（递归结论落地）、`RecursiveLayerReclaimStep`（递归器构建/逐层回收/上限）、`OutcomeFinalizeStep`（终态收口）、`OutputClaimStep`（输出目录认领）、`PostProcessSuccessStep`（成功后收尾：源包/其余物/发布）。
- 分卷/第二大步：`VolumeStepStep`（第二大步接线口）、`VolumeStepPreflightStep`（组入口开工前检查）、`VolumeStepFacts`（批首入口点名/产出链/第二大步事实位）、`VolumeLedgerStep`（分卷记账）、`VolumeHandoffStep`（交接登记）、`VolumeGatherStep`（收片/组内片编排）、`VolumeGatherCollectStep`（整组候选收集/参考名/槽位键/规范名准备）、`VolumeRepairStep`（缺卷补救/批前收卷）、`VolumeSlotFillStep`（缺槽补链接/打分分配）、`SplitVolumeAssembleStep`（整组缺卷拼装）、`GroupOrderTrialStep`（整组试开）、`StalledGroupStep`（停在中途组自证/缺名描述）、`PieceAdoptionStep`（收片采纳/路径红线）、`DeferredVolumeDeficitStep`（缺卷批末补判/链尾收口）、`ConsumedSettlementStep`（被别单接手的片/组结算）、`ContentGroupSettlementStep` / `ContentGroupFinalizerStep`（内容组源包结算/最终内容判决）。
- 源包/密码/引擎：`SourceProtectionStep`（用户源包就地保护/真名还原）、`PasswordPromptStep`（手动密码/密码提示/失败汇总/危险条目提示）、`EngineFallbackStep`（引擎回退/暂存校验）、`EmbeddedZipStep`（双面文件直解）。
- 接线：`ServiceForwarding`（搬进 `Services/*Step` 后留下的一行转发 + host 接口实现）。

> `VolumeStepFacts` 是协调器 partial，不是独立类；分卷第二大步的族算法与模型在 `Extraction/VolumeStep/`。

## 8. 唯一出口清单

- 文件事实：`FileNature.Inspect`
- 内容准入：`ContentAdmission.Probe`
- 内容身份：`FileContentProbe.Probe`
- 任务终态：`TaskOutcome`；状态文案：`StatusText`
- 第一大步账本/第二大步候选：`FirstStepFileLedger`
- 组分析：`VolumeCandidateDiscovery`；第二大步组事实：`VolumeGroupService`（唯一写者）；族仲裁：`VolumeFamilyArbiter` / `VolumeBoundaryPipeline`
- 轮判定：`RoundProductClassifier`
- 落点：`OutputPlacement`；第二大步工作区根：`SecondStepEntryRootResolver`
- 工作区：`PathService.WorkDirectory` / `WorkspaceRootResolver`
- 删除闸门：`Storage/RestItemPurger.cs`（五道门槛）；源包清理：`SourceCleanupService`
- 密码失败登记：`PasswordFailureRegistry`
- 进程：`ProcessStartInfo.ArgumentList`；只杀自己启动的 PID
