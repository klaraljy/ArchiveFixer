# 模块地图

> 适用版本：ArchiveFixer v0.2.2  
> 最后核对：2026-11-13，代码 HEAD `1a95ee52`  
> 状态：现行。只列关键类/职责；新增模块先更新本表。

## 1. 根与入口

| 位置 | 关键类 | 职责 |
|---|---|---|
| `App.xaml.cs` | `App` | 应用启动、全局异常、日志/设置/主题、单实例/窗口 |
| `MainWindow.xaml*` | `MainWindow` | 主窗口、页签、关闭/托盘、窗口状态 |
| `ViewModels/MainViewModel.cs` | `MainViewModel` | 任务集合、命令、汇总、日志、页面状态、设置编辑入口 |

## 2. Views

| 位置 | 职责 |
|---|---|
| `Views/Tabs/TaskTab` | 导入、任务列表、勾选、一键处理、暂停/停止、日志 |
| `Views/Tabs/ExtractionTab` | 嵌套层数、并发与空间、内容物保留关键词、落点 |
| `Views/Tabs/CleanupTab` | 源包操作、最后一层过程物操作 |
| `Views/Tabs/PasswordTab` | 统一密码、密码本、密码列表、每层上限 |
| `Views/Tabs/PackingTab` | 打包源、密码、分卷、落点、进度/结果 |
| `Views/Tabs/ReminderTab` | 一键确认、解压前提醒、完成提醒 |
| `Views/Tabs/EngineTab` | 引擎优先级、7z/UnRAR/Rar 路径、保留受损文件 |
| `Views/Tabs/SettingsTab` | 日志、安全上限、恢复默认、关于 |
| `Views/Tabs/HelpTab` | 内置说明、术语、快捷键 |
| `Views/*.xaml` | 确认/密码/选项/打包确认/删除预览等弹窗 |

## 3. ViewModels

| 文件 | 职责 |
|---|---|
| `ScanCoordinator` | 导入/追加/拖放、扫描、无用物剔除 |
| `OneClickCoordinator` | 多轮一键处理、续解、产物扫描、轮判定、第二大步、批末 |
| `PackingViewModel` | 打包页状态与命令 |

| `ExtractionCoordinator.*` | 单任务执行、调度、密码、递归、分卷、定稿、源包、工作区、批末（按 partial 分文件） |

## 4. Detection

| 文件 | 职责 |
|---|---|
| `FileNature` | `FileNatureCard` 唯一底层事实：格式、分卷身份/卷号、名字线索、媒体结构、物理身份 |
| `ContentAdmission` | 内容探测唯一准入：None/UserSource/VolumeCandidate |
| `FileContentProbe` | 内容身份：KnownContent/Archive/Unknown，浅/深探测与缓存 |
| `VolumeNumberFromContent` | RAR/ZIP 卷号/首卷/成员证据；RAR5 媒体前缀主头校验 |
| `VolumeContentInference` | 魔数格式识别、扩展名映射 |
| `EmbeddedArchiveLocator` / `TailArchiveScanner` / `EmbeddedArchiveDetector` | 内嵌归档/媒体前缀定位 |
| `FirstStepFileLedger` | 第一大步账本、第二大步候选、路径/事实保真 |
| `VolumeGroupDetector` / `VolumeGroupResolver` / `VolumePiecesFromCards` | 分卷组识别/顺序/事实 |
| `StandardNameFastPath` | 逻辑规范名快通道 |
| `FileIdentity` | 卷序列号+文件索引，改名/硬链接稳定身份 |
| `OrphanVolumeSetDetector` / `VolumeSlotScoring` | 孤立片/槽位评分 |

## 5. Extraction

| 文件 | 职责 |
|---|---|
| `RecursiveExtractor` + `Extraction/Recursion/*` | 递归入口 façade、契约、探测、收卷证据、结果与报告 partial |
| `RecursiveLayerPlanner` / `RecursiveSpannedZipStage` / `RecursiveResultBuilder` / `RecursiveFailureClassifier` | 递归路真类：层准备、跨盘 ZIP 收卷预检、失败收尾（结论/兜底/缺卷/层报告）、加密头分类 |
| `LayerExecutor` / `CandidateFailureClassifier` | 候选循环编排（列目录/跳过闸门/预算/探针/解压/成功校验）与单候选失败分类；输入走 `LayerExecutionState`、失败事实走 `CandidateFailureContext`/`CandidateFailureResult` |
| `WorkItem` / `LayerOutcome` / `LayerFailureContext` / `LayerPlan` | 递归路的模型对象（队列项、层结果、失败收尾输入、层准备结论） |
| `RoundProductClassifier` | 轮边界产物分类 |
| `VolumeCandidateDiscovery` | 同基名/分卷组分析 |
| `VolumeGroupEntryLayer` | 标准名入口层、硬链接/搬运、清理 |
| `SplitVolumeAssembler` | 容器首卷+后续卷拼装 |
| `StandardNameFastPath` | 分卷标准名/入口逻辑 |
| `VolumeProbeVerifier` | 只读试开/顺序验证 |
| `EmbeddedZipStreamExtractor` / `EmbeddedArchiveCarver` | 内嵌 ZIP 直读/抠取 |
| `OutputPlacement` / `ResultFinalizer` / `OutputVerifier` | 落点、定稿、校验 |
| `ProcessArtifactLayout` | 过程物/其余物目录与路径判定 |
| `PartialPublish*` | 部分完成发布计划/执行 |
| `SourceCleanupService` / `RestVolumeCompletenessGate` | 源包/其余物安全 |
| `ExtractionScheduler` / `SpaceGate` / `SpaceTrendMonitor` | 调度、空间门、空间曲线 |
| `WorkspaceStep` / `WorkspaceCleanupService` / `WorkspaceRootResolver` | 工作区解析/清理 |
| `PasswordEngineFallback` / `ZipAesCrypto` | 密码/引擎兜底、ZIP AES |
| `VolumeNamePlanner` / `VolumeNameRestorer` / `VolumeGatherPlanner` | 卷名规划、伪装名恢复、跨层/跨盘收卷；`VolumeNameRepair` 只留编排与 `TryApply` |
| `Extraction/Artifacts/*` | 过程物/源包搬运的公开类型各自一文件 |
| `Storage/RecycleBin/*` | 删除档位、请求/结果、安全闸门、回收站执行器各自一文件 |
| `Detection/VolumeGroups/*` | 分卷证据/裁决/试开类型各自一文件 |
| `Packing/Options/*` | 打包枚举、规则、路径、外层容器解析各自一文件 |
| `Models/Tasks/*` | `ArchiveTask` 的终态/原因/空间事实/源包搬运状态各自一文件 |

## 7. 唯一出口清单

- 文件事实：`FileNature.Inspect`
- 内容准入：`ContentAdmission.Probe`
- 内容身份：`FileContentProbe.Probe`
- 任务终态：`TaskOutcome`；状态文案：`StatusText`
- 第一大步账本/第二大步候选：`FirstStepFileLedger`
- 组分析：`VolumeCandidateDiscovery`
- 轮判定：`RoundProductClassifier`
- 落点：`OutputPlacement`
- 工作区：`PathService.WorkDirectory` / `WorkspaceRootResolver`
- 进程：`ProcessStartInfo.ArgumentList`；只杀自己启动的 PID

> 加新判据前先找上表出口；找不到再新建，不许在调用点复制一套。
