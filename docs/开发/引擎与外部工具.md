# 引擎与外部工具

> 适用版本：ArchiveFixer v0.2.4  
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 状态：现行。旧 WinRAR 参考/历史见 `docs/参考/WinRAR功能参考.md` 和 `docs/历史/`。

## 1. 分发边界

- 内置 7-Zip：`tools\7zip\7z.exe`（及许可证文本）；随包分发，遵循 LGPL/相关许可。
- 内置 UnRAR：`tools\unrar\UnRAR.exe`；随包分发，遵循 RARLAB 的 freeware 许可（允许随包，不得改/去广告等）。
- WinRAR 的 `Rar.exe` / `WinRAR.exe`：**共享软件，不随包分发**；程序只检测/调用用户自己装的那一份。
- 7-Zip、UnRAR 许可原文随包在 `tools/*/`；发布前复核 `LICENSE` 与许可文件。

## 2. 引擎选择

`EngineSelector`：

- 按能力筛选：不可用/不支持该格式的引擎跳过；
- 通过筛选后按 `EnginePriority` 排序；
- 默认优先级 `["winrar","sevenzip"]`：WinRAR 的 UnRAR 优先，7-Zip 兜底；
- `winrar-fallback` 只用于换引擎兜底，不在用户优先级表里。

## 3. 工具定位

`ToolLocator`：

- 7z：用户自选 → 程序 `tools\7zip`；
- UnRAR：用户自选 → 已装 WinRAR 目录 → 程序 `tools\unrar`；
- Rar：用户自选 → 已装 WinRAR；仅打包外层 rar 使用；
- 路径只在这里解析，其他模块不重复拼。

## 4. 执行

- 外部进程用 `ArgumentList`，不拼命令行字符串；
- 密码参数只进进程参数，不进日志；
- 读取 stdout/stderr，超时/取消只杀本程序启动的 PID；
- 7-Zip/UnRAR 退出码与输出关键字统一映射到 `StatusText`/`TaskReason`；
- 失败/部分完成保留引擎原话，日志脱敏密码。

## 5. 覆盖策略

- `OverwriteMode` 交给引擎：跳过/覆盖/自动重命名；
- UnRAR 不支持 7-Zip 的 `-aot` 那一档，界面/日志如实说明；
- `KeepBrokenFiles` 只对 UnRAR 生效；7-Zip 本身保留半成品，失败结论不变。

## 6. 打包

- 7z 分卷用内置 7-Zip；
- 外层 rar 用本机 `Rar.exe`；没有则自动 7z；
- 程序不复制、不随包分发 WinRAR 任何文件。
