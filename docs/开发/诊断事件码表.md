# 诊断事件码表

> 稳定错误码用于用户日志和诊断包。⛔ 错误码按问题分类，不按样本名、目录名、文件名生成。
> 已发布的码只追加，不改变含义。

| 错误码 | 组件 | 含义 | 代码入口 |
|---|---|---|---|
| `AF-APP-000` | Application | 未归类的应用错误 | `LogService.Write` 的 ERROR 兜底 |
| `AF-TASK-001` | ExtractionCoordinator | 任务最终失败 | `ExtractionCoordinator` 任务边界 |
| `AF-VERIFY-002` | OutputVerifier | 输出校验未通过 | `OutputVerifier.Verify` 的调用方 |
| `AF-VOLUME-003` | VolumeBoundary | 分卷组缺片/不完整 | `ExtractionCoordinator.VolumePreflight` |
| `AF-IO-004` | FileOperations | 文件移动、删除、改名、硬链接失败 | `FileOperations` / 路径预检 |
| `AF-ENGINE-005` | ArchiveEngine | 外部引擎调用失败或工具缺失 | `ToolLocator` / 引擎调用边界 |
| `AF-UI-006` | UiResponsivenessMonitor | UI 线程明显停顿 | `UiResponsivenessMonitor` |
| `AF-UNHANDLED-007` | App | Dispatcher/AppDomain/TaskScheduler 未处理异常 | `App.xaml.cs` |
| `AF-LOG-008` | LogService | 日志/诊断包写入失败 | `LogService` / `DiagnosticBundleService` |
| `AF-CONFIG-009` | SettingsService | 设置或配置文件失败 | `SettingsService` |
| `AF-PASSWORD-010` | PasswordService | 密码本读取、写入或匹配失败 | `PasswordService` |
| `AF-DECISION-011` | Decision | 关键判据给出否定结论 | `LogService.Criterion` |

## 排查顺序

1. 打开诊断包 `extra/summary.json`，取 `error_codes`；
2. 用码查本表，定位组件与入口；
3. 按 `operation/operation.jsonl` 的 `run/operation_id/task_id/span_id` 还原时间线；
4. 看 `exception` 字段（Type/Message/Inner/HResult/Stack）；
5. 没有异常时看最后完成的阶段和下一个未完成阶段。

## 新增规则

- 新错误码只追加，不复用旧码；
- 一个码只表达一个分类；
- 不允许按样本名/文件名动态拼码；
- 关键失败出口必须显式给码；兜底码只用于未分类错误；
- 诊断包中的码表来自代码常量，不手写第二份。
