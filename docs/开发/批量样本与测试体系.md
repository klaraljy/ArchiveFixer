# 批量样本与测试体系

> 适用版本：ArchiveFixer v0.2.2  
> 最后核对：2026-11-14，代码 HEAD `96f69d4f`  
> 状态：现行。旧的 120 批口径与旧测试流程已归档到 `docs/历史/旧测试体系/`。

## 1. 三件东西

| 组件 | 作用 |
|---|---|
| 造包器 | 生成 125 份样本 + `recipe.json` |
| 操作测试 | 把样本交给真实 `OneClickCoordinator` 跑，落运行记录 |
| 检测测试 | 只读 recipe + 运行记录 + 磁盘，逐条判红绿 |

造包器**只写备份目录**；操作测试写测试区；检测测试只读。

## 3. 125 份构成

| 类别 | 数量 | 说明 |
|---|---:|---|
| 普通 | 55 | 前 50 份 8 场景轮转；51–55 是同基名形状。测试操作只覆盖 Normal 1–40 的三项设置（20/20 位置，源包/过程物随机），不直接采用 recipe 的 scenario |
| 特定 | 20 | 1–10 旧形状；11–20 新形状 |
| 异常 | 25 | 缺片、坏片、空包、跨盘、危险/保留名、内容容器等 |
| 空间 | 15 + 10 | C01–C15 普通档，B01–B10 特定解压档 |

样本 ID 规则：

```text
普通：seed + 1 .. seed + 55
特定：seed + 100001 .. seed + 100020
异常：seed + 200001 .. seed + 200025
空间：C01..C15 / B01..B10
```

## 4. 造包

```powershell
pwsh -NoProfile -File "E:\DeepSeekProjects\ArchiveFixer\测试\造包器\造125批.ps1" `
  -SeedBase 928000000 `
  -Mode All -Section All
```

默认路径已经在生成器里指向 `测试\备份位置`、`测试\原物`，不传 `OutputRoot/ContentRoot/MediaRoot` 也能落在标准位置。生成后先看 `备份位置\<seed>-125批次-备份\.logs\造包.log`、`125-manifest.json`、`125-report.json`。

## 5. 跑操作

```powershell
pwsh -NoProfile -File "E:\DeepSeekProjects\ArchiveFixer\测试\造包器\125批测试操作.ps1" -Seed 928000000
```

底层等价命令（C# 路径改造完成前，测试仍读旧的 `Batch120Operation` 位置；改造后以标准日志位置为准）：

```powershell
$env:ARCHIVEFIXER_120_SEED = '928000000'
dotnet test tests\ArchiveFixer.Tests\ArchiveFixer.Tests.csproj `
  --filter "FullyQualifiedName~Batch120OperationTests"
```

- 不带 `ARCHIVEFIXER_120_SEED` 时两组测试自动跳过。
- 操作测试只负责“真跑并落记录”，不做期望值断言；异常样本也照跑。
- 一份失败只影响自己，不拖累其它样本。

## 6. 跑检测

```powershell
pwsh -NoProfile -File "E:\DeepSeekProjects\ArchiveFixer\测试\造包器\125批测试检测.ps1" -Seed 928000000
```

底层等价命令同上；检测报告固定写在 `测试\日志位置\<seed>-125批次-日志\检测\<样本>.json`，红项直接失败。已知检查：

- 普通：落点、内容字节、源包、过程物、组状态；
- 特定：解压成功/内容层；
- 异常：预期结论、源包保留、危险/受保护条目未落盘；
- 空间：空间门/预期阻断。

## 7. 换种子

标准位置已实跑：

```text
928000000：125/125 操作通过，125/125 检测通过
```

旧 927 只保留，不参与新标准流程。

造包器支持 `-SeedBase`；不要改样本 ID 公式。重造某类样本用 `-Section`，重造单份用 `-Mode Single -Only N -Force`。

## 8. 已知坑

- 造包器默认路径可能仍写着 H 盘旧位置；必须显式 `-OutputRoot/-ContentRoot/-MediaRoot`。
- 测试区与备份区不要混用；操作测试会复制样本到测试区，不会改备份。
- 空间样本 C/B 的 ID 不含 seed，换种子时不要与上一批测试区混在一起。
- 操作测试和检测测试是两个独立测试类；不要只用操作通过就宣布批次通过。
- 大批内容物（4,000 个 PNG）另有 `LargeContentScanTests`，不替代 125 批；它专门验证扫描准入次数。
- 旧的 120 批/80 份文档只作历史，不代表当前的 55/20/25/25 构成。
