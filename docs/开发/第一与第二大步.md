# 第一与第二大步

> 适用版本：ArchiveFixer v0.2.2  
> 最后核对：2026-11-11，代码 HEAD `23acb074`  
> 状态：现行。旧取证/交接记录见 `docs/历史/旧开发文档/第一与第二大步-旧版.md`。

## 0. 一句话

一个轮 = **第一大步**（单一完整包全部解压）+ **第二大步**（分卷只解一层）。轮末按产物分类决定下一轮从哪一步开始。

## 1. 第一大步

### 1.1 对象

只处理可证“单一完整包”：

- `FileNatureCard.BodyKind == SingleComplete`；
- 或已证明的媒体前缀完整归档（`EmbeddedOffset > 0`）；
- 普通单卷 ZIP/RAR/7z 由内容事实确认。

分卷首片/分卷片/名字槽/同基名兄弟证据成立 ⇒ **交接**，第一大步不调引擎。

### 1.2 流程

```text
识别（ArchiveDetectService + FileNature）
→ 内容物/APK 准入闸门
→ 伪装后缀修正（只改可证后缀；基名不动）
→ 源文件快照/缺卷/路径/预算/空间闸门
→ 引擎解压到 stage
→ 输出校验（非空/字节/清单）
→ 定稿到落点
→ 源包/过程物按档
```

### 1.3 分卷成员

- 不调第一大步引擎；
- 登记 `FirstStepFileLedger` 的交接事实（族/卷号/首卷/自述整包/名字槽/来源/层）；
- 原地不动，交第二大步。

## 2. 第二大步

### 2.1 候选

唯一来源：`FirstStepFileLedger`。

组键：`SecondStepBaseName + FileIdentity`；目录不是组键，同基名跨目录仍可成组。

候选只排除：

- 已消费源包；
- 0 字节；
- 普通媒体；
- 已证明的内容容器（ZIP 家族按条目深探测）。

裸 7z 中间片、脏名、无名字槽的稀疏片仍要进族 resolver，不能因“没有证据”提前排除。

### 2.2 组分析

`VolumeCandidateDiscovery` + 三族 resolver：

- 7z：首卷 `.001`；自述整包字节/片数；片数由事实推，不写死；
- 跨盘 ZIP：末片 `.zip` 是入口，EOCD 盘号/中央目录偏移；
- 通用 ZIP：`.zip.001..` 首片是入口；
- RAR5：内容卷号为主；RAR4 新/老：名字+末卷+试开。

判不出缺片就报缺，不调引擎、不删片。

### 2.3 入口层

- 完整组在 `.ArchiveFixer.work\group-entry` 建标准名硬链接/入口层；
- 源片保持原名，不靠物理改名；
- 用逻辑规范名（`StandardNameFastPath`）供引擎；
- 失败/缺片/判不出不动源片。

### 2.4 只解一层

- 引擎在入口层打开入口卷；
- 只解一层；内层包/内容物按正常定稿；
- 成功后按组收片；失败/部分完成按档保留；
- 同一组只点名一次，跟随卷不另行解压。

## 3. 轮判定

`RoundProductClassifier.Classify`：

- 产物是单一包 ⇒ 下一轮第一大步；
- 产物是分卷 ⇒ 下一轮第二大步；
- 其余是内容物 ⇒ 结束。

同一产物在不同轮角色可不同，每到轮边界按盘上事实重新分类，不继承上一轮角色。

## 4. 内容物

普通内容物不在第一/第二大步解压：自动路径不解、不递归、不改名、不搬、不删；只有用户源包或同基名/分卷候选才走 `ContentAdmission`。详见 `内容扫描与准入.md`。

## 5. 边界

- 源包永远按用户档，失败/取消不动；
- 过程物/其余物按清理页档；
- 危险条目/路径/预算/空间闸门不过 ⇒ 不动；
- 判不出不是“不是分卷”，只是“不动”。
