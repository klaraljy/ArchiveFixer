# 设置与行为矩阵

> 适用版本：ArchiveFixer v0.2.4
> 最后核对：2026-11-14，代码 HEAD `9e6e7b17`  
> 状态：现行。字段默认值/范围见 `设置项.md`；这里回答“这个设置影响哪条链”。

## 1. 扫描/识别

| 设置 | 消费点 | 行为 |
|---|---|---|
| `RecursiveScan` | `FileScanService` / `ScanCoordinator` | 文件夹导入是否递归 |
| `AutoScanAfterDrop` | `ScanCoordinator` | 导入后自动识别；所有导入入口 |
| `ScanMode` | `FileScanService` | 全部/已知归档后缀/可疑文件 |
| `IncludeHiddenFiles` / `IncludeSystemFiles` | `FileScanService` | 扫描是否纳入隐藏/系统文件 |
| `MaxFileSizeLimit` | `FileScanService` | 扫描阶段单文件 MB 上限，0=不限 |
| `UnknownFormatAction` | `ScanCoordinator` | 未知格式：标记/跳过/尝试解压 |
| `DefaultExtension` | `RenameService` | 智能修正默认后缀 |

## 2. 一次解压

| 设置 | 消费点 | 行为 |
|---|---|---|
| `ExtractToOriginalDirectory` / `CustomOutputDirectory` | `OutputPlacement` | 落点根 |
| `KeepArchiveNameFolder` | `OutputPlacement` | 固定建包名一层（归一化 true） |
| `ConflictAction` | `ConflictStep` | 解压落位冲突：跳过/覆盖/自动改名/询问 |
| `OverwriteMode` | 引擎请求 | 引擎侧覆盖策略 |
| `MaxRecursionDepth` | `OneClickCoordinator.RoundLimit` / 递归 | 1–10，层数=轮数上限 |
| `MaxParallelExtractCount` | `ExtractionScheduler` | 1–4 并发上限 |
| `EnginePriority` | `EngineSelector` | 能力筛选后的优先级 |
| `Custom*ExePath` | `ToolLocator` | 外部工具路径 |
| `KeepBrokenFiles` | UnRAR 请求 | 保留校验失败半成品（仍失败） |
| `AssembleSplitVolumesFromContainer` | `SplitVolumeAssembler` | 容器首卷接同目录后续卷 |
| 安全上限四项 | `ResourceBudget` / `ArchivePathGuard` | 解压前预算；超了整包拒绝 |
| `TestBeforeExtract` | `ExtractTaskMainStep` | 试解；无密码包会变慢 |

## 3. 密码

| 设置 | 消费点 | 行为 |
|---|---|---|
| `TryEmptyPasswordFirst` | `PasswordService` | 空密码是否先试；特定解压复用同一候选构造，空密码最多一条 |
| `UseGlobalPasswordForAllTasks` | `PasswordCandidatesStep` | 统一密码是否用于所有任务；输入值仅本批生效，不落盘 |
| `MaxPasswordAttemptsPerLayer` | `PasswordCandidatesStep` | 每层候选上限（1–1000）；特定解压也按此截断 |
| `EnableSidecarPassword` | `SidecarPasswordReader` | 从同目录说明文件提取候选 |
| `RememberPasswordList` | `PasswordListStore` | 密码列表跨重启保存（底层固定 true） |
| `PasswordBookPaths` | `PasswordService` | 多本密码本顺序 |

## 4. 源包/过程物/工作区

| 设置 | 消费点 | 行为 |
|---|---|---|
| `SourceHandling` | `SourceCleanupService` | 源包留下/就地删除（成功+校验后） |
| `RestHandlingAfterVerify` | `RestItemPurger` | 失败时最后一层过程物留下/彻底删除 |
| `KeepFailedWorkspace` | `WorkspaceStep` | 失败/取消工作区是否保留（固定 false） |
| `PartialPublishEnabled` | `PartialPublish*` | 部分完成发布（默认 false） |
| `CollectResultsToDirectory` / `CollectTargetDirectory` | `ResultCollector` | 成功产物归集 |
| `OpenOutputFolderWhenDone` | `PostProcessSuccessStep` | 成功后只打开输出文件夹 |

## 5. 打包

| 设置 | 消费点 | 行为 |
|---|---|---|
| `PackTargetMode` / `PackCustomOutputDirectory` | `PackingViewModel` | 最终包落点 |
| `PackSourceHandling` | `PackingCleanup` | 打包后源处理 |
| `PackRestHandling` | `PackingCleanup` | 打包过程物/其余物处理 |
| `CustomRarExePath` | `PackingService` | 外层 rar；不随包分发 |

## 6. UI/日志

| 设置 | 消费点 | 行为 |
|---|---|---|
| `EnableLog` / `VerboseLog` | `LogService` | 文件/详细日志 |
| `ReportDangerousEntries` | 解压前预检 | 统计可执行/脚本条目，只提示 |
| `RemindBeforeExtract` | `BatchReminderHandler` | 解压前提醒 |
| `SkipOneClickConfirm` | `OneClickCoordinator` | 一键确认框 |
| `LowProcessPriority` | `App.xaml.cs` | 进程优先级（固定 false） |

## 7. 读法

- 默认值和范围以 `AppSettings` 的初值、`CreateDefault()`、`Normalize()` 三处为准；
- 界面入口只影响“能不能改”，不改变消费点；
- 旧键仍能读入不等于仍生效；退役键见 `设置项.md` 第 8 节。
