## 5. 红检要求

新增/修改判据必须能临时撤掉后让对应用例变红；常见红检：

- 撤 `ContentAdmission` 的 `None` 闸门 ⇒ 普通产物探测用例红；
- 把内容探测放回 `FileNature` ⇒ 普通产物用例红；
- 撤 `FileNature` 缓存 ⇒ 同卡复用红；
- 撤 `prepared` 0 片保护 ⇒ SizeAnomaly 用例红；
- 撤 UI 前后台标记隔离 ⇒ `UiActivityTests` 红；
- 撤同基名/分卷过滤 ⇒ 136/336 形状或批次红。
