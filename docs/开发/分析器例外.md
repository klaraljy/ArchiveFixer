# 分析器例外（M2 基线）

产品项目启用 `AnalysisMode=Recommended`，但以下规则在当前代码库中属于“先记账、后偿还”的噪声/大规模改法，暂降为 `suggestion`，不阻塞构建。每条都必须在后续阶段被处理或继续说明理由；禁止新增 `NoWarn` 整类压制。

| 规则 | 当前量级 | 为什么暂缓 | 偿还阶段 |
|---|---:|---|---|
| CA1863 | ~516 | 建议改 `CompositeFormat`，是性能微优化，改动面大；先保留可读性 | M5 性能批 |
| CA1822 | ~208 | “成员可设为 static”会改公开/内部 API 形状，应与调用方一起评审 | M5 |
| CA1305 | ~200 | `IFormatProvider` 文化敏感；需要逐处确认日志/文件名/用户文案口径 | M5/M6 |
| CA1859 | ~98 | 返回具体集合类型是性能建议，可能与契约可读性冲突 | M5 |
| CA1068 | ~50 | `CancellationToken` 参数顺序，改动公共签名，需与测试/调用方一起 | M4/M5 |
| CA1865 | ~34 | `StartsWith(char)` 等微优化 | M5 |
| CA1805 | ~34 | 显式默认值初始化，纯风格/性能 | M5 |
| CA1861 | ~24 | 常量数组复用，局部性能 | M5 |

这份清单是**临时基线**，不是永久豁免。M5/M6 完成时更新数量；新增规则警告必须修，不能往这里加。
