# 最后一层过程物代码修正计划

前提：222.md 的口径已确认。

```text
源包从开始就是当前过程物；
本层解压成功 + 校验通过时立即删源；
失败/取消/未完成保留最后一层过程物；
空间不足覆盖普通档和特定解压档，但不绕 L4/L5 安全闸门。
```

本计划只修代码缺口；不新增删除路径，不改源包删除时机。

## 一、先写红检，不改产品代码

### 1. 空间不足 + Delete 必须仍保留最后一层过程物

测试：

```text
915000049 坏片
SpaceTightMode = true
RestHandling = Delete
失败后断言：
  LastProcessArtifactPath 非空且存在
  RestDirectoryPath 存在
  源包目录仍在
```

当前预期红：`PreserveCurrentProcessArtifact` 在 Delete 分支提前返回。

### 2. 组保留整组，但当前过程物指针必须是 group entry

测试：

```text
915000049 坏片，Keep
断言：
  RestDirectoryPath 下至少保留整组片数
  LastProcessArtifactPath 必须是 group entry
  不能是最后一片
```

当前预期红：循环保留时 `LastProcessArtifactPath` 被最后一片覆盖。

### 3. 重新 Merge 后旧入口必须清空

单元测试：

```text
ContentGroup 先 Merge 带 CanonicalEntryPath 的 prepared
再 Merge 不带入口的 prepared
断言 CurrentProcessArtifactPath 为空
```

当前预期红：只 set，不 reset。

### 4. SpaceTightPolicy 必须是唯一出口

单元测试：

```text
LastProcessOnFailureKeeps / RestOnFailureKeepsLastProcess
必须被实现读取，而不是只存在属性
```

## 二、代码修改顺序

### 1. PartialPublishStep

- `PreserveCurrentProcessArtifact` 先读批策略：
  ```text
  spaceTight && LastProcessOnFailureKeeps
  => 忽略普通 Delete，保留当前过程物
  ```
- 普通档的 Delete 行为保持不变。
- 空间不足只有一条：最后一层过程物固定保留。

### 2. 当前过程物指针

- 新增/复用“整组保留”调用时，先保留所有组入口链接；
- `LastProcessArtifactPath` 只写 group entry，不写最后一片；
- 组入口来自 `ContentGroup.CurrentProcessArtifactPath`，不能用路径列表最后一个。

### 3. ContentGroup

- `MergePrepared` 中：
  ```text
  有 CanonicalEntryPath -> set
  没有 -> clear
  ```
- `CurrentProcessArtifactPaths` 与入口路径保持同一批组事实。

### 4. 策略统一

- `SpaceTightPolicy` 的以下字段必须被实际消费：
  ```text
  SourceOnLayerSuccessDeletes
  LastProcessOnFailureKeeps
  RestOnFailureKeepsLastProcess
  PartialContentOnFailureDrops
  ```
- `SpecificExtractionBatch` 使用当前批同一策略，不自己新建等价策略。
- `RestHandlingStep` / `PartialPublishStep` 不再各自解释空间不足删除档。
- 保留现有 `PurgeLayerSourcePackage` 作为唯一删源出口。

### 5. 测试与矩阵

先跑定向红检，再改代码；修完按顺序：

```text

SpaceTightModeTests
SpecialExtractionPipelineTests

20 条异常
全量
format
```

最终目标仍是：

```text
50 普通 + 10 特定 + 20 异常 + 20 空间 = 100
```

## 三、禁止项

```text
禁止新增第二条删源路径
禁止链尾扫 Pending / 任务表 / 文件存在性猜
禁止按样本名加分支
禁止把源包删除提前到解压前
禁止用测试通过代替路径级断言
```
