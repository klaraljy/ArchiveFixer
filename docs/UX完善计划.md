## 1. 目标与边界

目标：把当前“能用”的 WPF 工具，提升到符合 Windows 桌面应用常识的体验；优先解决会让用户困惑、误以为程序没反应、或在小屏/高 DPI 下不可用的点。

不做：

- 不重写 WPF 架构，不换 WinUI。
- 不为“看起来现代”破坏现有操作习惯。
- 不在同一提交里同时改窗口壳和抽取核心。
- 不擅自改变密码存储方案；需要单独决策与迁移方案。

## 2. 已拍板的口径

1. **右上角 X**：WinRAR 式——空闲退出；有任务在跑时收进托盘，任务继续；不增加“关闭=退出/托盘”设置。
2. **托盘图标**：不提供“禁用托盘”开关；托盘保留，右键退出；忙碌时退出先确认。
3. **密码本**：DPAPI（当前 Windows 用户）加密；提供显式「导出明文…」/导入；导出只写副本，程序内部密码本不移动、不删除。

## 3. 分阶段执行

### 阶段 A：低风险、立刻改善（1 次提交）

- 提醒机制：所有需要用户注意的对话框最多响 **1 声**；不再 Strong=3 声。
  - 保留“只在窗口没到前台时提醒”的收窄判据；
  - 增加可关闭提醒音/闪光的设置（默认开，响一声）；
  - 验收：密码框/确认框/密码本各弹 1 次，只响 1 声，已在前台时不响。
- 修正主窗口 `MinWidth`/`MinHeight` 与注释不一致：
  - 注释和实际值必须同源；
  - 先用保守值（按 1366×768 / 125% 可用 DIP 定），不要继续写 1180。
- 修正主窗口默认尺寸：按当前工作区自适应，不固定 1400×900。
- 验收：1366×768、100%/125% 下主窗口四边可见、关闭/最小化按钮可达。

### 阶段 B：窗口、DPI、布局（P0）

1. 加入 `app.manifest`，声明 PerMonitorV2 DPI awareness。
2. 窗口位置/大小持久化：
   - 保存 left/top/width/height/maximized；
   - 启动时按当前所有屏幕做可见性归一化；
   - 显示器断开、分辨率变小、任务栏位置变化时不能恢复到屏幕外。
3. 主窗口最小尺寸按内容重新评估；选项卡增加横向滚动或折叠策略。
4. 子窗逐个复核：
   - 手动操作 1080 宽、改名 960 宽、密码列表 780 宽；
   - 小屏/高缩放下按钮不能出屏；
   - 长内容有滚动，保持 `IsDefault`/`IsCancel`。
5. 子窗任务栏策略：
   - 验证 `ShowInTaskbar=true` 是否产生多个任务栏按钮；
   - 需要时改用 owner/任务栏分组，而不是简单塞进任务栏。
6. 验收矩阵：
   - 1366×768、1920×1080、2560×1440；
   - 100%、125%、150%、200% 缩放；
   - 单屏、双屏、拔掉副屏后重启；
   - 左右 Snap、四分之一 Snap、最大化/还原。

### 阶段 C：托盘与关闭语义（P0）

1. 增加设置：`关闭按钮行为`：退出 / 最小化到托盘（默认按 §2 决定）。
2. 增加设置：`显示托盘图标`；关闭且窗口隐藏时必须有别的可见入口。
3. 首次隐藏到托盘时给一次说明（托盘气泡或首次提示），说清：
   - 程序还在跑；
   - 任务没有取消；
   - 从托盘左键恢复、右键退出。
4. 托盘菜单至少：打开、显示/隐藏主窗口、退出；退出必须真正结束进程。
5. 任务栏集成：
   - `TaskbarItemInfo` 进度/状态；
   - 需要时加 JumpList（最近目录/最近任务）；
   - 不在任务栏和通知区域同时显示互相矛盾的状态。
6. 验收：关闭/最小化/托盘恢复/忙碌中退出/第二次启动恢复，逐项跑通。

### 阶段 D：辅助功能、键盘、主题（P1）

1. 给关键控件补 `AutomationProperties.Name` / `LabeledBy`：
   - 主窗口选项卡、主导航、密码框、统一密码显隐、日志、失败/取消按钮。
2. 键盘可达性：
   - Tab 顺序、焦点框、Enter/Esc、菜单访问键；
   - 所有危险确认弹窗有明确的默认按钮和取消路径。
3. 高对比度/主题：
   - 固定色值改为可替换资源；
   - 至少支持 Windows 高对比度；暗色主题单独评估。
4. 200% 文本缩放复核：
   - 密码页、任务列表、日志、打包确认、密码列表。
5. 验收：Accessibility Insights / Narrator + 纯键盘走完“导入→一键处理→查看失败→退出”。

### 阶段 E：密码与隐私（P1，需单独决策）

1. 复制密码后剪贴板定时清理（例如 30 秒），或提示用户手动清理。
2. 密码输入/显示控件补屏幕阅读器标签；显示密码时保持“这是敏感字段”的语义。
3. 评估 DPAPI 加密 `passwords.txt`，保留显式导入/导出明文能力。
4. 进程命令行里的 `-p<明文>` 是外部引擎限制：
   - 文档明确风险；
   - 评估短期凭据/临时环境变量等替代方案，不能静默忽略。
5. 验收：密码不出现在日志/异常/诊断包；列表显示/复制/清空行为有一致提示。

### 阶段 F：反馈、对话框、状态（P1）

1. 主窗口底部进度显示当前任务名/百分比/剩余；不要只有不确定进度条。
2. 失败/取消/空间不足的状态色、图标、文案统一；不把“没做成”显示成成功。
3. `PasswordPickerWindow` 的直接 `MessageBox.Show` 改为项目统一自绘对话框。
4. 错误文本可复制、脱敏；长路径可选中。
5. 提醒音/闪光设置与阶段 A 的设置项合并，不重复造开关。

### 阶段 G：安装、更新、签名（P2）

1. 安装包/卸载页文案与实际日志位置保持一致（已完成文案修正，需重新生成安装包验收）。
2. 代码签名：正式发布前购买/配置证书，给 exe/dll/安装包签名。
3. 更新策略：手动下载覆盖 / 内置更新 / 不更新，三选一，写进发行说明。
4. 静默安装、升级、卸载保留数据各跑一次。

## 4. 每阶段验证门

每个阶段独立提交，必须满足：

- `dotnet build ArchiveFixer.slnx -c Release --no-incremental`：0 错 0 警；
- `dotnet format ArchiveFixer.slnx --verify-no-changes`：通过；
- 相关定向测试通过；
- 涉及共享窗口/布局/设置的阶段跑全量；
- UI 改动附截图或自动化证据（缩放、DPI、托盘、键盘）；
- 不把没有实际运行的 UI 检查写成“通过”。

## 6. 建议执行顺序

```text
A 提醒一声 + 主窗最小尺寸/默认尺寸
→ B DPI/窗口状态/子窗布局
→ C 托盘与关闭语义 + 任务栏进度
→ D 辅助功能/高对比度
→ E 密码与隐私
→ F 反馈/对话框一致性
→ G 签名/安装/更新
```

A、B、C 是用户每天都能感知的部分，优先做；D/E 需要更多回归；F/G 放在发布前。

## 7. 回滚

- 每个阶段单独 commit；
- 出问题回退该阶段 commit，不回退用户数据；
- 窗口状态、托盘设置新增字段必须向后兼容，旧配置缺字段时用默认值。
