## 0. 怎么测、怎么记

**每条都按同一个格式**：

- **做什么** —— 照着点，别跳步；
- **看到什么算通过** —— 逐条对，**全部对上才算这条通过**；
- **不通过时记什么** —— 把这几样抄下来，开发者一眼能定位。

**通用记录格式**（每条不通过都写这一行）：

```
条目编号 | 实际看到的现象 | 任务列表里「状态」「错误信息」两列的原文
        | data\logs\ 里最新那个日志文件（整个文件最好）| 能不能重现（重来一次还这样吗）
```

**两个通用前提**（后面不再重复）：

- 全程**不要**用真实密码 / 真实个人目录做测试材料；测试包一律用**合成密码**（例如 `TestPass123!`）。
- 出问题的第一件事：把 `data\logs\` 里**最新那个日志文件**留下来（菜单「工具 → 导出日志」）。

### ★ 只有 10 分钟？先过这 7 条（2026-09-23 新增功能的速测）

按顺序做，**每条都能单独判断通过/不通过**；任一条不对就把现象记下来（格式见上）。

| # | 做什么 | 看到什么算通过 |
|---|---|---|
| 1 | 双击桌面 `ArchiveFixer` → 看**启动**与**数据目录** | 正常打开、没有错误弹窗；`<程序目录>\data\` 里出现 `logs\`（**不在 C 盘**） |
| 2 | 把一个**普通包**放进测试目录 → 添加文件夹 → 勾选 → 一键处理 | **只弹一个确认框**，正文两行 = 「内容物会生成在：…」+「其余物：…」；**确认之前进度条不动**（点确定后才开始动）；处理完状态是**解压成功**；产物在输出目录里；源包在 `其余物\` 里（可还原） |
| 3 | 同一个目录里先放一个 `说明.txt`（或 `.url`）再解压 | 解压前弹**一个**合并提醒（列出"可能的无用物"）；点「继续处理」后整批照常跑完；那个 txt **一个字节都没被动** |
| 4 | 解压进行中，把任务列表里某个**还没开始**的包在资源管理器里改个名/删掉 | 它变成「**源文件已变化**」并写清是哪个文件、哪一项变了；**其它任务不受影响**；源包没有被搬动、没有产物 |
| 5 | 让程序弹一次**需要你处理的窗口**（例如解压一个加密包、密码本没命中时的手动输入框）：先把浏览器切到前台再等它弹 | 任务栏图标**一直闪**（闪到你点它为止）+ 响**三声**；窗口自己跑到最前面；点它之后**闪烁与声音都停** |
| 6 | 菜单「工具 → 打包文件夹为加密分卷…」→ 选一个测试文件夹 A → **外层容器保持默认「rar」** → 密码填 `TestPass123!` → 开始 | 生成 **两个**东西：与 A 同级的文件夹 `A名_打包`（默认名，里面是 `A名.7z.001`，超过 512 MiB 会继续 `.002`）+ 同级的 `A名_打包.rar`；结果区给出**容器类型 + 产物路径 + 分卷清单 + "复制密码"**。窗口里另有两个可选项：「**7z**」（不需要装任何东西）与「**不做外层**」（只出分卷）—— 三个选项**一直可点**；没装 WinRAR 时选 rar 会**明确报错并给三条出路**，**不会偷偷换成别的容器** |
| 7 | 第 6 步完成后，**用 WinRAR 双击那个 rar**（输密码） | 打得开；里面是**文件夹 `A名_打包`**，它里面是那些 `.7z.001` 分卷；分卷用 7-Zip/WinRAR 输密码解出来就是 A 原来的内容。（第 6 步若选的是 7z 外层，就用 7-Zip 打开那个 `.7z`，结论一样） |

> ⚠ 这 7 条里**第 7 条会真的用到你的 WinRAR**（本机已装）。共享软件试用 40 天后需自行购买许可，那是你与 RARLAB 的事，与本程序无关。

| N13 | **①输出位置 ⇄ ②落点位置必须同步**（第 31 条，你报过两次）：在①「任务」页点「输出位置」那格的**「选择…」**挑一个目录（例如 `H:\…\CCC`）→ 切到②「解压方式」页 → 再看「落点（解压到哪）」；然后反过来：在②页点「指定位置 + 同名子文件夹」并「选择」另一个目录 → 切回①页 | ① 切到②页时：那一档**已经是「指定位置 + 同名子文件夹」**（不再是「同名子文件夹」），**「指定位置」框里就是刚才那个目录**、而且是**可用状态**（不再灰着写「（不适用）」）；② 反方向同理：①页那格显示新目录（中间省略），勾选框**不是**「未指定位置」。⚠ 两处的路径与档位**任何时候都必须一致** |

### 准备测试材料（一次性，约 5 分钟）

两条路，任选：

**① 用你手头真实的包（最真实，推荐）** —— 挑 3~5 个：一个普通 zip/7z、一个后缀被改坏的、
一个分卷的、一个加密的。放在一个**专门用于测试**的目录里（例如 `D:\af-test\pkg\`），
**别拿你唯一一份重要数据的目录来试**。

**② 现场造一套合成材料**（包里不含任何真实密码）：

```powershell
# 程序目录（把下面这个路径改成你解压出来的位置）
$af = "D:\Tools\ArchiveFixer"
$sz = "$af\tools\7zip\7z.exe"          # 用程序自带的 7z 造材料

# 造点内容
New-Item -ItemType Directory -Force "D:\af-test\payload" | Out-Null
1..300 | ForEach-Object { "第 $_ 行 测试内容 abcdefghijklmnopqrstuvwxyz" } |
    Set-Content "D:\af-test\payload\文本.txt" -Encoding UTF8
$f = [System.IO.File]::Create("D:\af-test\payload\大文件.bin"); $f.SetLength(6MB); $f.Close()

$t = "D:\af-test\pkg"
New-Item -ItemType Directory -Force $t | Out-Null

# 普通包
& $sz a "$t\普通.zip" "D:\af-test\payload\*"
# 伪装后缀（把一个 zip 改名成 .mp4）
Copy-Item "$t\普通.zip" "$t\伪装.mp4"
# 加密包（连文件名一起加密，合成密码）
& $sz a -pTestPass123! -mhe=on "$t\加密.7z" "D:\af-test\payload\*"
# 分卷包（每卷 1MB）
& $sz a -v1m "$t\分卷.7z" "D:\af-test\payload\大文件.bin"
# 双面文件（前面是正常数据、尾部挂一个 zip）—— 找一个几 MB 的 mp4/jpg 代替 sample.mp4
cmd /c copy /b "D:\af-test\payload\大文件.bin"+"$t\普通.zip" "$t\双面.mp4"
```

造完 `D:\af-test\pkg\` 里应该有：`普通.zip`、`伪装.mp4`、`加密.7z`、`分卷.7z.001`、`双面.mp4`。

> ⚠ 每次测完想重来，就把 `D:\af-test\` 整个删掉重新造一遍 —— 这样每次都是干净现场。

### A3 伪装后缀：识别 + 改名预览（确认）
