## 已确认的四个缺陷

1. 特定解压用包所在目录当设备根，同一物理盘拆成多个池。
2. `target` 只用于日志，不限制实际启动。
3. 特定解压没有设置 `StartTime`，完成观察/容量反馈没有执行。
4. `CapacityPolicy` 只从初始值向上探测，HDD 从 3 起步时不会回试 1/2。
