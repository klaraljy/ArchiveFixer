# Legacy 代码归档区

这个目录只存放**已经退出编译**的旧代码/旧实现，不是现行源码，不参与 `dotnet build`。

规则：

- 不直接删除旧代码；替换/拆分前先把旧版本按相对路径复制或移动到 `legacy/refactor-20261112/`。
- 归档目录不对应任何 namespace，不加入 `.csproj`；不能从现行代码反向引用。
- 每个归档文件在 `legacy/refactor-20261112/清单.md` 登记：原路径、归档时间、替换它的新文件、是否仍被测试/文档引用。
- 恢复时按清单原路径放回；不得从归档目录直接改现行行为。
- 用户数据、`H:\` 原件、`E:\ArchiveFixer\data` 不进入本目录。

当前阶段：P0 结构规范整改。第一批归档将从 `MainViewModel` 拆分开始；在拆分前不移动任何仍参与编译的文件。
