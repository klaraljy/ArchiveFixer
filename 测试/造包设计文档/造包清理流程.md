# 造包清理流程

> 适用版本：ArchiveFixer v0.2.4
> 状态：现行。清理只处理测试临时物，不碰备份、造包器、原物、设计文档。

## 1. 绝对不可删/不可改

```text
测试\备份位置\*             ← 批次母本
测试\造包器\*               ← 所有生成器/总控脚本
测试\原物\*                 ← 造包原物
测试\造包设计文档\*         ← 六份流程与设计
```

- 不重命名、不移动、不覆盖已有批次备份；
- 不用 `Remove-Item -Recurse` 指向这些目录；
- 旧 `E:\AF` 文件默认不自动清理。

## 2. 可清理

| 位置 | 何时可清 | 说明 |
|---|---|---|
| `测试\测试位置\<seed>-125批次-测试未指定位置` | 该批次操作/检测完成并留档后 | 只清本次 seed/批次 |
| `测试\指定位置\<seed>-125批次-测试指定位置` | 同上 | 只清本次 seed/批次 |
| `测试\日志位置\<seed>-125批次-日志` | 用户确认归档/完成后 | 先确认检测结果已留档 |
| `测试\修改测试位置\<ChangeId>` | 用户手动确认后 | 简单验收目录，不自动清 |
| 样本 `.build` | 对应样本完成/失败留档后 | 不在备份位置清 |

## 3. 清理前

1. 确认目标路径是 `测试\...` 且位于正确根；
2. 确认不是备份/造包器/原物/设计文档；
3. 确认该批次操作/检测结果已保存；
4. 列出将删除的文件数/大小；
5. 用户明确确认后执行。

## 4. 推荐清理顺序

```text
旧操作测试位置
→ 旧指定位置
→ 旧日志（确认汇总已留）
→ 旧修改测试位置
```

不清理备份；不清理当前正在用的批次。

## 5. 禁止

- 一键递归清理整个 `测试\`；
- 清理时使用通配符指向 `备份位置`；
- 删除失败现场后才开始排查；
- 清理旧 `E:\AF`/旧 120 备份；
- 自动定时删除修改验收目录。

## 6. 保留策略

- 备份：永久保留（用户自行决定）；
- 当前批次日志/汇总：至少保留到该批次验收结束；
- 修改验收：默认手动清理，不自动淘汰；
- 旧目录：用户自行删，测试流程不碰。
