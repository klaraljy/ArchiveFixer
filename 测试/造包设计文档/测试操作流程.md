# 测试操作流程

> 适用版本：ArchiveFixer v0.2.2  
> 批次：125 批  
> 状态：现行。操作只读备份、复制后运行，不回写备份。

## 1. 输入与输出

```text
输入备份：测试\备份位置\<seed>-125批次-备份
未指定位置：测试\测试位置\<seed>-125批次-测试未指定位置
指定位置：  测试\指定位置\<seed>-125批次-测试指定位置
操作记录/日志：测试\日志位置\<seed>-125批次-日志\操作\
```

不允许：

- 直接对备份目录跑程序；
- 改备份里的 recipe/包；
- 把操作产物写回备份；
- 用 `_tmp`、`E:\AF\120批操作` 等旧路径。

## 2. 前置检查

1. 备份存在，含 `.125-generated`、`125-manifest.json`、`125-report.json`；
2. manifest 的 `seedBase` 与目录 seed 一致；
3. 125 份样本齐全；
4. 目标测试位置/指定位置/日志位置为空或属于同一 seed 的旧运行（清理流程允许时才清）。

## 3. 复制规则

- 先复制一份完整备份到 `测试位置\<seed>-125批次-测试未指定位置`；
- 需要指定位置运行的样本复制到 `测试指定位置`；
- 复制只改测试位置，不改备份；
- recipe 里 `placement=Original` 的样本走“未指定位置”树；
- `placement=Specified` 的样本走“指定位置”树；
- 8 场景中 4 个 Original、4 个 Specified 各占一半；Normal 1–40 五轮完整覆盖；
- 测试位置和指定位置不得混用同一个目录。

## 4. 运行

统一入口：

```powershell
pwsh -NoProfile -File "E:\DeepSeekProjects\ArchiveFixer\测试\造包器\125批测试操作.ps1" `
  -Seed 928000000
```

等价底层命令（排障时用）：

```powershell
$env:ARCHIVEFIXER_120_SEED = '928000000'
dotnet test tests\ArchiveFixer.Tests\ArchiveFixer.Tests.csproj `
  --filter "FullyQualifiedName~Batch120OperationTests"
```

注意：

- env 名目前是历史名 `ARCHIVEFIXER_120_SEED`，值用 125 批 seed；后续改代码时再统一，文档先如实写；
- 不带 seed 时测试会跳过，不算通过；
- 操作测试按样本独立跑，一份失败不拖累其它样本；
- 异常样本也照跑，预期失败由检测判。

## 5. 日志（强制）

每次操作必须复制/保留：

```text
测试\日志位置\<seed>-125批次-日志\操作\<sampleId>.json
测试\日志位置\<seed>-125批次-日志\操作\<sampleId>\...（运行日志）
```

- 不再依赖 `keepLogs` 可选参数；
- 失败/取消/超时也要保留；
- 日志里密码必须脱敏；
- 检测流程必须读日志，不能只看 JSON/磁盘。

## 6. 运行记录

每份至少记录：

- sampleId、category、placement；
- recipe 的源包/落点/源包档/过程物档；
- 跑前/跑后文件快照；
- 任务名、终态、原因、输出路径、内容物路径；
- 错误/异常；
- 起止时间/耗时；
- 日志位置。

记录写到 `日志位置\操作\`，不写备份。

## 7. 8 选项核对

每次操作后由检测核对：

| 位置 | 源包 | 最后一层过程物 | 样本来源 |
|---|---|---|---|
| Original | KeepInPlace | Keep | Normal 1,9,17,25,33 等 |
| Original | KeepInPlace | Delete | Normal 2,10,18,26,34 等 |
| Original | DeleteInPlace | Keep | Normal 3,11,19,27,35 等 |
| Original | DeleteInPlace | Delete | Normal 4,12,20,28,36 等 |
| Specified | KeepInPlace | Keep | Normal 5,13,21,29,37 等 |
| Specified | KeepInPlace | Delete | Normal 6,14,22,30,38 等 |
| Specified | DeleteInPlace | Keep | Normal 7,15,23,31,39 等 |
| Specified | DeleteInPlace | Delete | Normal 8,16,24,32,40 等 |

具体样本以 recipe 为准；矩阵覆盖由 `Batch120Verify`/后续 `Batch125Verify` 核对。

## 8. 失败与重跑

- 单样本失败：保留现场与日志，记录原因，不删其它样本；
- 整批中断：只重跑未完成/失败样本，不重造备份；
- 重跑前只清该项目标测试位置/日志，不能删备份；
- 重跑仍用同一 seed/同一备份，不改 recipe。

## 9. 禁止

- 在备份上直接运行；
- 把测试位置/指定位置的文件写回备份；
- 操作阶段修改 recipe 或样本；
- 用操作通过代替检测通过；
- 不看日志就判绿。
