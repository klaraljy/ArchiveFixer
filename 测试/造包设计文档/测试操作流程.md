# 测试操作流程

> 适用版本：ArchiveFixer v0.2.4
> 批次：125 批  
> 状态：现行。操作只读备份、复制后运行，不回写备份。

## 1. 输入与输出

```text
输入备份：测试\备份位置\<seed>-125批次-备份
未指定位置：测试\测试位置\<seed>-125批次-测试未指定位置
指定位置：  测试\指定位置\<seed>-125批次-测试指定位置
操作记录/日志：测试\日志位置\<seed>-125批次-日志\操作\
```

不允许：

- 直接对备份目录跑程序；
- 改备份里的 recipe/包；
- 把操作产物写回备份；
- 用 `_tmp`、`E:\AF\120批操作` 等旧路径。

## 2. 前置检查

1. 备份存在，含 `.125-generated`、`125-manifest.json`、`125-report.json`；
2. manifest 的 `seedBase` 与目录 seed 一致；
3. 125 份样本齐全；
4. 目标测试位置/指定位置/日志位置为空或属于同一 seed 的旧运行（清理流程允许时才清）。

## 3. 复制规则

- 先复制一份完整备份到 `测试位置\<seed>-125批次-测试未指定位置`；
- 需要指定位置运行的样本复制到 `测试指定位置`；
- 复制只改测试位置，不改备份；
- Normal 1–40 的 `placement` **不再读 recipe**，由测试操作代码按 ID 表决定：20 份 Original / 20 份 Specified；
- Normal 41–50、51–55 仍按 recipe 的固定设置；51–55 不参与本次随机和半数；
- 测试位置和指定位置不得混用同一个目录。

操作设置表在 `tests\ArchiveFixer.Tests\Batch120\BatchNormalSettings.cs`；同一 seed 可复现，例如 Normal 1（seed 为 929999999 时 ID=930000000）为 `Original + DeleteInPlace + Keep`。

## 4. 运行

统一入口：

```powershell
pwsh -NoProfile -File "E:\DeepSeekProjects\ArchiveFixer\测试\造包器\125批测试操作.ps1" `
  -Seed 928000000
```

等价底层命令（排障时用）：

```powershell
$env:ARCHIVEFIXER_120_SEED = '928000000'
dotnet test tests\ArchiveFixer.Tests\ArchiveFixer.Tests.csproj `
  --filter "FullyQualifiedName~Batch120OperationTests"
```

注意：

- env 名目前是历史名 `ARCHIVEFIXER_120_SEED`，值用 125 批 seed；后续改代码时再统一，文档先如实写；
- 不带 seed 时测试会跳过，不算通过；
- 操作测试按样本独立跑，一份失败不拖累其它样本；
- 异常样本也照跑，预期失败由检测判。

## 5. 日志（强制）

每次操作必须复制/保留：

```text
测试\日志位置\<seed>-125批次-日志\操作\<sampleId>.json
测试\日志位置\<seed>-125批次-日志\操作\<sampleId>\...（运行日志）
```

- 不再依赖 `keepLogs` 可选参数；
- 失败/取消/超时也要保留；
- 日志里密码必须脱敏；
- 检测流程必须读日志，不能只看 JSON/磁盘。

## 6. 运行记录

每份至少记录：

- sampleId、category、实际 placement / SourceHandling / RestHandling；
- recipe 的样本形状与期望结果；
- 跑前/跑后文件快照；
- 任务名、终态、原因、输出路径、内容物路径；
- 错误/异常；
- 起止时间/耗时；
- 日志位置。

记录写到 `日志位置\操作\`，不写备份。

## 7. 操作设置分布

Normal 1–40 只要求位置 20/20；源包、最后一层过程物纯随机，不要求各半，也不要求每个组合 5 份。当前固定表分布：

| 位置 | 源包 | 最后一层过程物 | 份数 |
|---|---|---|---:|
| Original | KeepInPlace | Keep | 4 |
| Original | KeepInPlace | Delete | 5 |
| Original | DeleteInPlace | Keep | 7 |
| Original | DeleteInPlace | Delete | 4 |
| Specified | KeepInPlace | Keep | 6 |
| Specified | KeepInPlace | Delete | 5 |
| Specified | DeleteInPlace | Keep | 6 |
| Specified | DeleteInPlace | Delete | 3 |

- 8 个组合都至少出现一次；
- 具体哪份 ID 对应哪组，以 `BatchNormalSettings.cs` 的表为准；
- 检测核对的是操作记录里的实际设置，不再拿 recipe 的 scenario 当操作设置；
- 41–50 失败样本、51–55 同基名样本不参与这张表。

## 8. 失败与重跑

- 单样本失败：保留现场与日志，记录原因，不删其它样本；
- 整批中断：只重跑未完成/失败样本，不重造备份；
- 重跑前只清该项目标测试位置/日志，不能删备份；
- 重跑仍用同一 seed/同一备份，不改 recipe。

## 9. 禁止

- 在备份上直接运行；
- 把测试位置/指定位置的文件写回备份；
- 操作阶段修改 recipe 或样本；
- 用操作通过代替检测通过；
- 不看日志就判绿。
