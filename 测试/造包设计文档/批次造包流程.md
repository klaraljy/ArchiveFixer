# 批次造包流程

> 适用版本：ArchiveFixer v0.2.4
> 造包器：`E:\DeepSeekProjects\ArchiveFixer\测试\造包器\造125批.ps1`  
> 版本：`125-20261111-01`；修改时间：2026-11-11  
> 状态：现行。旧 120 批次、旧备份不迁移、不改动。

## 1. 用途与边界

批次造包器只负责生成 **125 份固定结构的样本 + recipe**，供后续“测试操作”和“测试检测”使用。

它不做：

- 不跑 ArchiveFixer；
- 不改程序、不改测试代码；
- 不生成“代码修改验收”的小样本（那个用 `代码修改验收造包.ps1`）；
- 不覆盖、不删除已有批次备份。

测试\原物\生成的媒体\     gen-p01..p12（图片）/ gen-v01..v12（视频）

旧 `E:\AF\造125批.ps1`、`E:\AF\造包设计\原物` 只作备份；新运行只认 `测试\`。

## 3. 参数

```powershell
pwsh -NoProfile -File "E:\DeepSeekProjects\ArchiveFixer\测试\造包器\造125批.ps1" `
  -SeedBase 928000000 `
  -Mode All -Section All
```

可覆盖参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `-SeedBase` | `917000000` | 新批次建议用 928000000；旧 927 不动 |
| `-OutputRoot` | `测试\备份位置` | 批次根 |
| `-ContentRoot` | `测试\原物\困难内容` | 普通内容物来源 |
| `-MediaRoot` | `测试\原物\生成的媒体` | 媒体前缀来源 |
| `-SevenZip` | `E:\ArchiveFixer\tools\7zip\7z.exe` | 引擎 |
| `-Rar` / `-WinRAR` | 本机 WinRAR | 共享软件，不随包分发 |
| `-Password` | 内置测试密码 | 样本加密密码 |
| `-Force` | 关 | 只重建点名的样本，不整批删 |
| `-KeepWork` | 关 | 保留样本 `.build` 现场 |
| `-Mode` | `All` | `All` / `Single` / `SelfCheck` |
| `-Section` | `All` | `Normal` / `Specific` / `Abnormal` / `SpaceC` / `SpaceB` |
| `-Only` | 0 | 配合 `-Section` 只造第 N 份 |

命令示例：

```powershell
# 自检，不落盘
... -Mode SelfCheck

# 只造 Normal 第 3 份
... -SeedBase 928000000 -Mode Single -Section Normal -Only 3

# 重造某类
... -SeedBase 928000000 -Mode All -Section Abnormal -Force
```

## 4. 125 份构成

| 类别 | 数量 | ID 规则 | 说明 |
|---|---:|---|---|
| Normal | 55 | `seed+1..seed+55` | 1–40 八场景；41–50 缺片/坏片；51–55 同基名 |
| Specific | 20 | `seed+100001..seed+100020` | 1–10 旧形状；11–20 新形状 |
| Abnormal | 25 | `seed+200001..seed+200025` | 异常/边界/内容容器 |
| SpaceC | 15 | `C01..C15` | 普通空间矩阵 |
| SpaceB | 10 | `B01..B10` | 特定解压空间矩阵 |

总数固定 125。`Mode SelfCheck` 校验：

```text
Normal=55（45 成功 / 5 缺片 / 5 坏片；Original 30 / Specified 25）
Specific=20
Abnormal=25
Space=15+10
total=125
```

## 5. 8 场景矩阵（造包器 recipe，不是测试操作设置）

Normal 1–40 按 `(Index-1) % 8` 轮转；每 8 份覆盖一次完整矩阵（共 5 轮）。  
⚠ 这是**造包器写入 recipe 的样本场景**；测试操作会按 `BatchNormalSettings.cs` 覆盖 Normal 1–40 的三项操作设置（20/20 位置，源包/过程物随机），不要拿本表当测试操作分布。

| # | placement | sourceHandling | contentHandling | recipe 落点 |
|---:|---|---|---|---|
| 0 | Original | KeepInPlace | Keep | 原位置；源包不动；最后一层过程物留 |
| 1 | Original | KeepInPlace | Delete | 原位置；源包不动；最后一层过程物彻底删除 |
| 2 | Original | DeleteInPlace | Keep | 原位置；成功后源包就地删；过程物留 |
| 3 | Original | DeleteInPlace | Delete | 原位置；源包/最后一层过程物都按删除 |
| 4 | Specified | KeepInPlace | Keep | 指定位置；源包不动；过程物留 |
| 5 | Specified | KeepInPlace | Delete | 指定位置；源包不动；过程物删 |
| 6 | Specified | DeleteInPlace | Keep | 指定位置；源包就地删；过程物留 |
| 7 | Specified | DeleteInPlace | Delete | 指定位置；源包/过程物都删 |

测试检测核对的是**测试操作记录**里的 8 种设置组合（Normal 1–40），不是直接拿这张 recipe 表；操作分布见 `测试操作流程.md`。

## 6. Normal 55

### 6.1 Normal 1–40：成功样本

- 5 层包，最后一层固定分卷；
- 内容物约为 4–5 MiB（视内容源大小）；
- 3 个单包位置 + 2 个分卷层位置（最后一层固定分卷）；
- 格式随机组合：单包 7z/rar5/zip；分卷 vol7z/volrar5/volzip7z/volrar4/volziprar；
- 每份带伪装/媒体前缀/包装（`wraps`）；
- 每份 recipe 记录 layers、files、baseName、mediaPrefix、wraps、expected*。

### 6.2 Normal 41–45：缺片

- 最后一层 5 卷，删除中间一卷；
- 期望：缺卷/部分完成，不调引擎、不误删；
- `FailureCombos` = 0,1,2,3,4；`FailurePlacements` 前 5 个 = Specified。

### 6.3 Normal 46–50：坏片

- 最后一层 5 卷都在，把中间片前 4096 字节写成 0xA5；
- 期望：损坏/部分完成，不误报成功；
- `FailureCombos` 后 5 个 = 5,6,7,0,1；`FailurePlacements` 后 5 个 = Original。

### 6.4 Normal 51–55：同基名单包套分卷

内层是 4–5 片 7z 分卷，外层是**与片同基名**的单一包：

| # | 外层 | 场景 |
|---:|---|---|
| 51 | tar | 同基名，KeepInPlace/Keep |
| 52 | 7z | 同基名，KeepInPlace/Keep |
| 53 | rar | 同基名，KeepInPlace/Keep |
| 54 | tar | 同基名，DeleteInPlace/Delete |
| 55 | tar | 同基名 + 结果归集 |

期望：外层与内层同基名不混成一组；内层分卷按组处理；不重复解。

## 9. Space 15+10

### 9.1 SpaceC（C01–C15，普通档）

类型轮转：

```text
C01 ample, C02 largest, C03 allblocked, C04 corrupt, C05 ample,
C06 largest, C07 allblocked, C08 corrupt, C09 ample, C10 largest,
C11 allblocked, C12 corrupt, C13 ample, C14 largest, C15 allblocked
```

每份 5–6 个包；`corrupt` 第一包损坏；自由空间/保留 64 KiB/并发 2 写入 recipe；`expected.blocked`/`failed` 由空间计划生成。

### 9.2 SpaceB（B01–B10，特定解压档）

类型轮转：

```text
B01 ample, B02 largest, B03 allblocked, B04 corrupt, B05 ample,
B06 largest, B07 allblocked, B08 corrupt, B09 ample, B10 largest
```

每份 5–6 个包；形状轮转 `direct / two-layer / three-layer / last-folder / volume / same-base`；同样写 space/expected 字段。

## 10. 产物与自检

批次根：

```text
<seed>-125批次-备份\
├─ <sampleId>\recipe.json
├─ <sampleId>\原包\...
├─ .logs\造包.log
├─ .125-generated          ← 只写 seed
├─ 125-manifest.json       ← 每份 id/category/placement/recipe
└─ 125-report.json         ← generatorVersion/generatedAt/seedBase/total/counts/failures
```

`-Mode SelfCheck` 必须通过：

```text
SelfCheck OK: Normal=55(45/5/5, 30/25) Specific=20 Abnormal=25 Space=15+10 total=125
```

生成器只删除**本次失败/点名重建**的样本目录；不整批删，不覆盖已有批次；已有批次必须有匹配 `.125-generated`，否则拒绝写入。

## 11. 备份不可变

- `测试\备份位置\<seed>-125批次-备份` 是只读母本；
- 生成器不得删除/改名整个批次；
- `-Force` 只能重建明确点名的样本；
- 测试操作只复制，不回写备份；
- 清理流程永不自动删备份。
