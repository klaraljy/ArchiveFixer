## 四、分卷处理

最后一层的每一片：

```text
片 1：外层再压缩 2 次
片 2：外层再压缩 1 次
片 3：不套层
片 4：1 次或 2 次
...
```

每个样本都保证 `0 次 / 1 次 / 2 次` 都出现。

每个外层套层使用单一压缩包，格式随机：

```text

```

每个分卷片放在**独立目录**：

```text
文件\层级1\层级2\层级3\片-001\
文件\层级1\层级2\层级3\层级4\片-002\
文件\层级1\层级2\层级3\层级4\层级5\片-003\
```

保证：

- 同组片不放在同一目录；
- 目录深度至少 3 层；
- 每片路径互相独立；
- 第一大步只看见单一包装，不直接处理裸分卷片。

## 纯随机规则

每个最终可见文件独立执行两次旧版困难伪装：

```text
第一次：从旧版 5 法 + EEE 中随机一种
第二次：再随机一种
```

每个参数纯随机：

- 插入位置随机；
- 插入字符随机；
- 插入长度随机；
- 是否保留卷序号随机；
- 是否删除整段后缀随机；
- 是否污染 `part` / `.001` / `.z01` 随机；
- 最终假后缀从字符池随机生成，不用 `a1/b2/c3` 这种顺序。

例如同一个样本里可能出现：

```text
111.part1.rar → 111.part1.7qx
111.part2.rar → 111.par删除2
111.part3.rar → 111_中文3.z
111.part4.rar → 111.q!w
```

也可能是：

```text
111.7z.001 → 111.7z.00删除1
111.7z.002 → 111.7z.2@@
111.7z.003 → 111.7z.删除
```

具体叫什么完全由该样本种子决定。

## 不能出现的固定模式

- 不按卷号生成固定后缀；
- 不让 001 永远对应某类；
- 不让所有片使用同一种伪装；
- 不在 recipe 里把“第几卷对应什么后缀”写成产品可读的规则；
- 程序只能从字节、内容卡、组证据里判断，不能靠造包规律。

## 保留的硬性要求

- 每个分卷片至少一次伪装命中卷标记或归档后缀；
- 每个最终可见文件至少两次独立伪装；
- 最终不留下干净的 `.rar / .7z / .zip` 标准名；
- 每一片独立随机；
- 外层套层、分卷片都执行；
- 媒体前缀文件名只用 `.mp4/.jpg/.png`，不套归档后缀伪装。

## 记录方式

recipe 只记录事实：

```text

```

不写“a1 对应第1卷”这种可供程序反推的规则。
